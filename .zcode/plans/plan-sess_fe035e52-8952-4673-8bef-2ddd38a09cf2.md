# 3.0.0.11 — U1Q/U1C 连续段合并为一趟 + 偏移线交叉根治 + U1C 车道拆分

## Context（为什么做）

用户报告与需求（2026-11-09）：
1. **现存 bug：U1Q 生成平行线会与基线交叉**。根因在 `ParallelCurveAnnotator.cs:563-606`：多段线源直接用 AutoCAD `GetOffsetCurves` 且把返回的全部碎片上图，不做"是否仍在同一侧"校验；带拐角路径偏移距离超过拐角可达距离时偏移线自交翻侧。
2. **U1Q/U1C 要支持连续段合并为一趟**：框选多段线（连通组各成一趟），一条连续偏移线 + 一个标注代替逐段标注。
3. **长度口径**：标注第二行长度按成员线段上的 U1L 毫米标求和推算（无标签的段用几何长度兜底），四舍五入到 10mm（统计契约要求结尾为 0，`TextParser.cs:30-32`），用户仍可手改。
4. **布局车道**：U1L 毫米标（内圈贴线，默认下方）与 U1Q（上方 15mm）默认不变；U1C 拆出独立配置，默认下侧外圈（偏移 210，避开 U1L 文字带 ~180），根治 U1Q/U1C 共用配置导致的完全重叠。

用户已拍板：非连续选集=每个连通组各成一趟（不报错）；U1C 同期支持合并。U1C 合并标注的长度保持现行 2000mm 占位规则不变（DEVELOPMENT.md 既有业务约定，本次不动）。

## 改动清单

### ① 新增 Core 纯几何（无 AutoCAD 依赖，可单测）
- `src/UNCAD/Core/Geometry/OffsetPolylineBuilder.cs`：给定有序顶点链 + 侧向 + 偏移距离 → 解析式逐段偏移 + 拐角 miter 斜接（斜接腿超 4×偏移时退化为 bevel 倒角），**每步校验偏移顶点不翻侧**（到最近源段的带符号距离 ≥ -容差），返回偏移折线顶点。弧段由调用方细分（最大矢高 1mm）成短直线段进链。这替代 Polyline 源的 `GetOffsetCurves` 路径——交叉从构造上不可能。
- `src/UNCAD/Core/Geometry/ParallelRunPlanner.cs`：端点容差（1.0，对齐 U1LX 口径）连通分组 + 链排序，每个连通组 = 一趟，输出有序成员 + 总几何长度。

### ② Cad 层
- 新 `src/UNCAD/Cad/ParallelRunGeometry.cs`：读源曲线 → 提取顶点（Polyline 弧段细分）喂给 planner；构造偏移 Polyline 实体；**U1L 标签长度推算**——扫选集内文本的 `UNCAD_U1LX` XData（复用 `QuickLineMetadataStore`）建"线句柄→毫米值"映射（复用 `QuickLineMillimeterText` 解析），成员无标签用几何长度，合计四舍五入到 10。
- `src/UNCAD/Cad/ParallelCurveAnnotator.cs`：新增按趟生成入口（选集先经 `ParallelRunPlanner` 分组）；Polyline 源偏移改走 `OffsetPolylineBuilder`（修交叉）；输出实体写新元数据字段 `RUN`（成员句柄 "|"-连接），`SOURCE` 保留=首成员句柄（向后兼容现有读取方）。`CollectPrevious`/`ErasePrevious`/`ResolveSourceIds` 扩展：命中任一 RUN 成员即整趟替换。
- `src/UNCAD/Cad/ParallelAnnotationMetadata.cs`：新增 `RUN` 字段读写 + `TryReadRunHandles`；新增"任意成员段切线一致"检查（复用 `MatchesAnySegmentTangent` 逻辑遍历成员）。

### ③ Features 层
- `src/UNCAD/Features/Unq/UnqFeature.cs`（U1Q1/2/4）：选集→分趟→逐趟生成；标注长度=推算值；命令行报告"共 N 趟"。单段选择=一趟，行为同样切到推算长度（D-050 记录此变更）。
- `src/UNCAD/Features/Conduit/ConduitFeature.cs`（U1C）：同样的合并机制；长度保持 2000mm 占位。
- `src/UNCAD/Features/Fill/BridgeLabelMigrationWriter.cs`：角度修复的前置一致性检查在 RUN 存在时遍历全部成员（防合并标注落在非首成员段上被误修角度）。

### ④ U1C 配置拆分 + U1SET
- `src/UNCAD/Infra/ConfigKeys.cs`：新增 `UNC_CONDUIT_SIDE`（默认 "0" 下侧）、`UNC_CONDUIT_LINE_OFF`（默认 210）、`UNC_CONDUIT_TEXT_OFF`（默认 0）；键缺失时回退旧 `UNQ_*` 值（老用户配置兼容）。字高继续共用 `UNQ_HEIGHT`。
- `src/UNCAD/UI/Wpf/Settings/SettingsDrawPage.xaml` + `SettingsWindow.xaml.cs`：U1C 卡片加"标注侧/偏移距离"控件，说明文案改为"不再与桥架共用"。

### ⑤ 不需要改的（确认过）
- 统计引擎：标注仍是两行 MText（`AnnotationLabelPair`），`StatCalculator` 按文字解析，零改动；长度结尾 0 由推算器保证。
- 3D 预览 `ReadBridges`：按 `SOURCE` 句柄分组——一趟的全部输出共享 SOURCE=首成员 → 天然一趟一组，零改动。
