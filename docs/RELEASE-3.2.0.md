# UNCAD Pro 3.2.0

发布日期：2026-11-15

UNCAD 3.2 | 自动优化——等测草图一键重排 + 自动拱桥。新命令 `Xauto`（D-053）：
框选完整图框，按毫米标注自动重排比例并自动开交叉拱桥；既有命令行为不变，
U1R 拱桥几何抽取为共享实现（交互不变）。

## 新增

- **`Xauto` 自动优化（D-053）**：
  - **比例重排**——复用 U1L3D/U13D 的等测 3D 重建链路（`QuickLineIsometricSceneBuilder`），
    把显示距离换成真实毫米值重新展开，再投影回草图平面：重排后每段图上长度
    **正比于其真实毫米值**；未确认的占位段（尾部 00mm 且无完成标记）按当前长短
    等比缩放，重排后仍是占位值待 U1LX 确认。
  - **短段保可读**——短段钳到逐段下限 max(1.5×拱桥直径, 毫米标文字宽×1.15)，
    洞和标注文字都放得下；比例系数以**图框可用空间**为目标（边界内缩一个洞径），
    整草图共用一个比例铺满该空间并联合居中，分量间相对位置不变
    （图框过小时回退原图包络内重排）。
  - **自动拱桥**——重排后在最终几何上检测 LINE 交叉，用等测重建的相机深度
    （z−x−y，视线零向量 (1,1,−1)）判定前后：**靠近相机的线自动开半圆洞**
    （直径沿用 U1SET 的 U1R 直径设置）；高处线跨越低处线，符合等测俯视直觉。
  - **安全边界**——共享端点/丁字连接是连接点不开洞；无法判定深度的交叉
    （单侧不可分类/投影族不同/等深即三维同点）跳过并点名，可手动 U1R 补；
    分量内含未标注或不可分类线段时**整分量跳过并点名**，绝不撕烂草图；
    洞距不足/贴端点的洞丢弃并点名。
  - **零副作用**——一个写事务一次 U 整体撤销；不改标注文字、不写
    frameinfo_json/CABLE_INFO、不联网；开过洞的线自动重挂 U1LX 关联
    （COMPLETED 保留），U1LX/U1F/U1U 后续读写不受影响。
- **共用底座**：U1R 拱桥几何抽取为共享 `ArchBridgePolyline`（单洞/多洞统一规划，
  U1R 交互行为不变）；等测投影与深度判定沉淀为 Core 纯逻辑 `IsometricProjection`。

## 改进

- **功能区图标统一单色（AutoCAD 原生风）**：全部命令图标统一为浅灰线性
  （`UiTheme.RibbonIcon`），取代旧的"一命令一色"商务配色——深色主题下与
  AutoCAD 原生功能区观感一致，命令区分回归形状+文字标签；锁定测试防分色回潮。
- **版本展示一律详细四段号**：启动动画、关于页、更新弹窗标题、U1SET 概览、
  配置分享记录、授权心跳 UA 统一显示 `X.Y.Z.第四段`（如 3.2.0.0）——现场排障
  一眼可知客户跑的是哪个补丁；更新日志比较与"已看版本"存储仍按三段
  （升级弹窗时序不受影响）。

## 已知限制（详见 docs/KNOWN-ISSUES.md）

- 已手动开过洞的 Polyline 不参与重排与交叉检测（洞位随重排会失位，需删洞重跑）。
- 交叉检测范围 = 本次框选图框内的全部 U1L 线（跨图框交叉可识别，框外线不参与）。
- 重排不做标注防重叠：密集短段的毫米标注可能相互靠近，需手动微调。
- 未确认占位段按当前图上长短参与整体缩放，其毫米值不被猜测或改写。

## 3.2.0.1 补丁（2026-11-15）

- **修复 Xauto 重排两处现场报告**：①**短段比毫米标还短**——旧下限只保
  1.5×洞径没算标注文字宽度，现逐段下限 = max(1.5×洞径, 标注文字宽×1.15)
  （文字宽 ≈ 0.9×U1L 字高×字符数）；②**重排挤在原图小范围**——旧算法以
  原图包络封顶（画得小就永远小），现按 D-053 修订以**图框可用空间**为目标
  （边界内缩一个洞径，75000×7500 的图框就铺满它）：整草图共用一个比例系数
  二分拟合联合包络、联合居中于图框中心、分量间相对位置不变；图框小到内缩
  为负时回退旧行为。新增回归：目标空间放大+居中 / 标注下限 / 双分量同比例
  保相对位置（SketchProportionPlannerTests 9/9）。

## 3.2.0.4 补丁（2026-11-15）

- **U1F = 重新定义（D-052 附录7，用户规格）**：①第一步无条件清理图框所有
  旧信息——旧 JSON 记录不再用于恢复/预填（CABLE_INFO 恢复兜底与"复制源

  仅 U1U——图上可见标记是现场意图）。③正常求和（已吸收标记排除防双算）。
  ④写入。**U1U 语义全部不变**（守卫/恢复/复用/搬场重绑照旧）。
- **毫米标判据收紧**：必须整数以 0 结尾 + mm 后缀（`3000mm` ✓；
  `3000`、`550mm`、小数、多行 ✗），收窄误吸收轴号/序号的风险。

## 3.2.0.7 补丁（2026-11-16）

- **修复：U1U 复制图框要跑两次才能得到正确结果**（用户报告附日志）：首跑因
  外来 JSON 守卫不吸收复制残留毫米标（防静默继承，正确），但首跑写侧同时把
  JSON 重盖成本框句柄——"外来"信号就此消失，第二跑把同一根残留标当"现场意图"
  吸收。现在**首跑就把残留标值作为设备内预留建议值带出**（清单确认窗/批量
  弹窗预填 + "复制残留毫米标，请核对"备注，与 D-052-B 复制源预填同语义：
  预填+核对，不是静默继承），首跑即得正确预留；图上文字仍保留。
- **XSTS 新增「未上图机台」名单**（现场驱动：清单 144 台只有 49 台上图，
  95 台盲区此前靠手工 VLOOKUP 拼名单）：全图帧扫描对账档案——档案机台 −
  全图机台 = 盲区名单；Excel 新增「未上图机台」页、结果窗新增「未上图」
  页签与徽章，按字母前缀分组摘要（PSP×10、OHVC×10…）。
- **近名报警**：盲区机台与图上机台编辑距离 ≤2 时点名"疑似画错名"
  （现场实例：清单 MSRTL04 ↔ 图上 MPSTL04）；图上选中机台在档案无记录且
  与档案近名时进异常清单——"就差一两个字母"从静默变可见。
- **XLAYOUT 筛选表达力升级**：区间词 `M603-M612`（数字界锚定——`M6030`
  不再被 `M603` 子串误捞）、前缀词 `MS*`、排除词 `!MS*`（可组合
  `AMHS !MS*`）；普通词的子串包含 OR 语义不变。
