# UNCAD Pro 3.0.0

发布日期：2026-11-03

3.0 是一次整体升级：界面全量迁移 WPF、图框数据随块存储、数据源与输出结构重做。
D-039 开发通道（3.0.0-dev.1 ~ dev.18，共 18 个验收装机包）随本版收官；
升级后 AutoCAD 2022 需重启一次完成插件注册。

## 新增

- **UI 全量 WPF 化（D-038/D-046）**：全部 21 个业务窗体迁移到 WPF-UI（Fluent 风格），
  深浅色主题、卡片布局、Enter 确认 / Esc 取消；统一设计令牌 FluentKit——
  11 个设置页共用一套字号/间距/卡片样式；所有窗口尺寸钳制到屏幕工作区 92% 并居中启动，
  低分屏不再截断。WinForms 旧版同批删除。
- **图框数据随块存储（D-040）**：frameinfo_json 迁入图框块内 FRAMEINFO 文字属性
  （模板 FRAME_20261102），图框复制/移动数据零丢失；U1F/U1U 自动把四代旧图框迁移到新模板，
  迁移不改表格尺寸（真机自检门禁 `UNCAD_MIGRATION_SELFTEST` 强制）。
- **网络机台数据源（D-041）**：U1SET/U1DATA 支持 HTTP/HTTPS 地址——仅下载、零上传、
  100MB 上限、20 秒超时；下载或解析失败时保留上一次成功快照并给出中文原因。
  绘图命令仍只读本机 SQLite 快照、永不联网，启动不自动刷新。
- **一个机台一个文件夹（D-042）**：BOQ / DWG / PDF 都写在 `<输出根>\<机台ID>\` 里，
  不再按图纸名或类别分层；写盘前预检文件占用。
- **设备内预留自动识别（D-043）**：U1F/U1U 识别现场老习惯的横排毫米数标注
  （如设备旁手写的 2000），自动吸收为设备内预留并在写图时删除标注；
  恰有一处才自动取值，多处时点名交人工确认。U1SET「清单与表格」可关。
- **U1F 缺回路照常填写（D-044）**：整机回路校验未通过时图纸照常填写
  （机台ID/清单/块属性/预留），只跳过该机 BOQ，补全后执行 U1S 补清单；
  U1S/U1DWG 保持硬门禁。现场可以边画边填。
- **XLAYOUT 三种排列方案（D-045）**：按机台完整性（完整在前，默认）、按机台 ID 顺序、
  按上游编号（同一 U_上游编号 排到一行，未配上游归最后一行）；行内回路按机台 Excel 行序；
  选择窗记住上次选择。
- **批量结果窗**：批量 U1U / U1DWG / U1PDF 结束后弹结果窗——每台一行的图框数/表格行/
  属性项/BOQ 状态与文件路径、每份 PDF 的成功/失败/原因；命令行只留一行摘要，
  逐步进度在进度窗、明细在结果窗与日志。
- **机台状态徽章与下一步指引**：XSTS / XLAYOUT 窗口顶部徽章行（完整/缺回路/多出/无基准
  各带台数与语义色）+ 下一步行动指引；XSTS 摘要同步输出机台分布。
- **U1F 机台选择窗重做**：相似建议浮层下拉（不顶布局）、回路筛选框与「显示 X / N」计数、
  长文本省略号+悬浮看全文、列表与预览随窗口弹性伸缩。

## 修复

- **幽灵机台**：图框移动后遗留的 frameinfo_json 块会被几何归属错误认领
  （统计多出机台、U1U 认错机台）；现 JSON 写入 `meta.frameHandle`，
  句柄不符即忽略外块并提示清理，老 JSON 无句柄保持兼容。
- **XLAYOUT 与 XSTS 结论相反**：回路齐全但有重复图框的机台被误标"缺回路"；
  现红只留给"应有的回路本次没见到"，重复/多出归黄，统计窗新增「详情」列点名原因。
- **单框 U1U 变更对比失真**：对比窗改在清单确认窗之后、用最终清单行构建，
  展示的米数变更与实际写入一致。
- 桥架/线管标注、统计汇总、面板选择等细节修正见开发版说明（docs 与仓库历史）。

## 变更

- **FillFeature 拆分**：1425 行上帝类拆为 8 个阶段服务（余 695 行），
  电缆预留纯逻辑下沉 Core 可独立单测；行数守卫测试防回潮。
- **发布双门禁**：`UNCAD_PERF_SMOKE`（合成大图时间预算）与 `UNCAD_MIGRATION_SELFTEST`
  默认随 `release.ps1` 执行，不达标不出包。
- 性能：大批量路径减少重复扫描；U1F/U1U 不再构建等轴测上传数据（2.10 起延续）。

## 加固

- 登录凭证改为 Windows DPAPI 加密存储（旧明文首次读取自动升级，无感）。
- 日志中的账户名统一脱敏；在线登录页拦截一切新开窗口，防钓鱼跳转。
- 分层守卫测试冻结模块边界（Core 禁依赖 AutoCAD/WinForms/WPF 等）。

## 升级说明

- 在线授权包（LicenseMode=Online），客户与有效期数据来自 `pro.key`，不嵌入程序。
- 从任意旧版本（1.x / 2.x / 3.0 验收版）直接安装即可；首次打开 CAD 后如未出现
  UNCAD 选项卡，执行一次 `RIBBON` 命令。
- 老图框在首次 U1F/U1U 时自动迁移到 FRAME_20261102 模板，表格尺寸不变。
