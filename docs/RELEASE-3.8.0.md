# UNCAD Pro 3.8.0

发布日期：2026-11-25

## 3.8.0.13（2026-11-27）

打通跨 DWG 文件复制整只已填图框（搬场重绑）的完整链路：

- **修复跨图句柄校验反转**：目标 DWG 中不存在原图框句柄时不再误判为“原框还在本图”，确保整只图框跨文件复制后能够识别为搬场并保留原 `frameinfo_json` 数据。
- **修复同底图衍生 DWG 句柄撞车误杀**：当目标图纸中恰好存在相同十六进制句柄的另一张不同机台/回路图框时，校验其身份后再判断是否冲突，不再将跨图搬场误判为同文件复制（同一机台同回路留在原图时仍维持同文件复制隔离）。
- **保留历史选择与对比信息**：更新阶段的电缆替代型号恢复、母线插接箱选择及更新对比窗统一携带图框物理身份，不再因跨文件复制而清空重问；覆盖写入后自动更新为新图框句柄。
- **提示**：跨文件复制请连同图框块本身一起复制，并建议一并携带 `UPSTREAM_INFO` 上游块以便区分同名回路。

## 3.8.0.12（2026-11-27）

- **多行属性清理与读取统一**：`U1F` 与复制图框清理旧属性时，同步清空多行属性（`IsMTextAttribute`）的 `MText` 内容及动态块 JSON 属性；读取 `UPSTREAM_INFO`、`DEVICENAME` 等物理属性时同步支持多行属性格式。
- **写入继承隔离**：`U1U` 写入合并内嵌或遗留 `frameinfo_json` 块时校验图框句柄归属，避免同机台其他图框的遗留记录回流污染。
- **窗口异步关闭保护**：`Xmerge` 选择窗在后台扫描期间关闭时立即停止后续界面更新。

## 3.8.0.11（2026-11-27）

- **跨文件复制框同名回路识别修复**：物理身份新增读取上游块 `UPSTREAM_INFO` 首行作为上游编号；当机台、回路名或上游编号任一与源框 `frameinfo_json` 不符时，丢弃源框旧 `CircuitKey`，按实际回路归属或弹出选择窗确认，不再把同名不同上游的回路全部判成台账第一条；复制框不再继承源框的预留与替代型号历史。

## 3.8.0.10（2026-11-26）

- **出图白线问题修复**：`U1L`、`U1LX` 新建线条与毫米标注不再继承当前 `CECOLOR` 真彩白，实体颜色统一固定为 `ByLayer`；执行 `U1F` / `U1U` 时自动将法定图层（`U_CABLE`、`U_TRAY`、`U_CONDUIT`、`U_HOSE`）上已有的真彩白（`#FFFFFF` / ACI 255）实体归回随层并汇报数量，解决白纸出图漏线与漏字问题。

## 3.8.0.9（2026-11-26）

- **工程结构与发布流程清理**：收敛 BOQ、提交表、DWG、XSTS、XLAYOUT 与缓存文件的原子写盘替换逻辑，清理过期 WinForms 遗留代码；新增基于 Tag 的 GitHub Actions 自动打包发布工作流。

## 3.8.0.8（2026-11-26）

- **3D 预览柱网与回路展示升级**：按图框平面内刻度以 `4.8 m` 跨距铺满全楼板柱网交叉坐标牌（自动避让、缩放渐显）；电缆路由统一采用醒目亮橙色粗管展示；上游端与设备端轴位牌固定停留在各自网格夹角并与实际端点连线标示。

## 3.8.0.7（2026-11-26）

- **预览配色与轴位排版优化**：取消电缆按等测轴 XYZ 分色，统一改为单色电缆与简洁图例（橙=电缆、红=桥架、青=线管）；数字与字母轴号沿楼板外圈相邻两边排开；端点轴位牌落在网格夹角以直观展示设备偏离轴心的距离。

## 3.8.0.6（2026-11-26）

- **预览取景与标签避让**：3D 视角改为围绕实际线路范围自适应取景，避免大跨度楼板把线路压扁；标签按“米数/桥架/软管 > 端点/设备/楼层 > 轴位”优先级同屏避让，米数统一按米（如 `8 m` / `0.3 m`）显示；修复缺字段触发相机异常的白屏问题。

## 3.8.0.5（2026-11-25）

- **U1U 预览引擎回归 WebView2 + three.js（WPF 自动兜底）**：确认窗左侧 3D 主渲染切换为内置本地 `Web/QuickLineOrbit` 页面；WPF 3D 场景作为底层即时常驻兜底，当本机缺失 WebView2 运行时或加载失败时自动展示原因并切回 WPF，确保任何环境下均不白屏；确认窗按左右 1:1 对半布局放大至 `1440×900` / `1440×820`。

## 3.8.0.4（2026-11-25）

- **真跨距 `4.8 m` 轴位网格**：每根柱网线严格对应一个轴号并保持 `4.8 m` 间距，不再按两端总长做线性拉伸；两端位移偏差对半分摊以保证设备落入各自网格内；支持方向自动判断，图面距离与台账轴位跨数不符时直接点名提示。

## 3.8.0.3（2026-11-25）

- **跨层高度口径修正**：跨层校验统一从“上游楼层地面”量至“设备端”（计入插座盘离地 `1 m` 以及立管底起点），高差区间与 `U1SET` 标高清单联动并在报警中写明依据。
- **单行桥架标注与规格宽度**：识别单行写法（如 `梯形桥架200Wx100H-1300mm`）与 `宽Wx高H` 宽度，并按原约定跳过含“共用”字样的共享桥架文字。

## 3.8.0.2（2026-11-25）

- **失效关联与拐角多段线识别**：清理句柄已失效（`0` 或原实体已删）的 XData 关联，使复制后带死关联的 `300mm` 等标注可正常几何归位；一笔画拐角多段线在填充/更新阶段按段拆解并独立挂标；排除电缆型号中的 `mm²` 与软管长度属性误报。
- **插座盘整体抬高与贴线文字**：插座盘对应整条重建路线直接抬高 `1 m`；米数、桥架、线管、软管标签沿各自线段方向贴线固定；修复单楼层图框预览空引用失败。

## 3.8.0.1（2026-11-25）

- **楼层线框与旧图桥架识别**：楼层平面改为边框与柱网线框绘制，避免半透明深度缓冲遮挡跨层线路；支持竖排及非平行旧图框桥架文字按文字外框中心匹配红线宿主；扩展闭合共线多段线、3D 多段线、样条曲线及无实线线性标注识别。

## 3.8.0（基础版，2026-11-25）

### U1U 3D 预览重做（D-059）

- 预览仅绘制台账对应的楼层线框、轴位网格、路由与上游柜，大幅削减场景三角面数量，移除旧版简化参照建筑与独立外部预览进程 `UNCAD.Preview.exe`。
- 上游柜按台账盘柜类型就位（I-Line 盘落地、插座盘离地 `1 m`、母线插接口按端点高度），跨层线路自动执行层高差校验并给出只读提示。

### 路由与标注识别增强

- 桥架与线管按“趟”汇总，标注长度代表整趟总长，宿主依次按元数据、红线拆分就近及最近单段恢复；所有电缆毫米标逐一校验归属并点名未归属标注与缺失的上下游轴位块。
- **`U1UL`**：支持将靠位置配对、未带关联元数据的历史毫米标一并归位（保持原所在侧、沿线位置、文字与字高不变）。
