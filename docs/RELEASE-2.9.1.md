# UNCAD Pro 2.9.1

发布日期：2026-11-01

本版三件事：**图框升级 xframe_v2**（旧图框自动迁移）、**frameinfo_json 升级 v2**（结构更紧凑、有硬性长度上限）、**U1U 增加电缆预留**（盘内 + 设备内）。

## 1. 图框 xframe_v2

- 模板 XFrameTemplate.dwg 改为动态块 xframe_v2；旧 frame_20260812 / frame / xframe 图框仍可读取，U1F/U1U 首次写入时自动迁移。
- 迁移不改变已有清单表/行/列的尺寸（D-004）。
- 新定义里没有的旧属性（FRAMEINFO_JSON / BRIDGE_FRAME_INFO / CONDUIT_INFO）会从块参照上移除；JSON 身份改由独立的 frameinfo_json 块维护。
- **2.9.1 修复**：迁移会先移除图框上的内嵌 FRAMEINFO_JSON，而旧代码在迁移之后才去读它，导致旧图框的替代型号/预留/更新历史丢失。现在读取范围包含图框块本身，且一定早于迁移。

## 2. frameinfo_json v2

- 嵌套结构 identity / upstream / downstream / cable / drawing / meta / changes，所有键必出（空值写空串）。
- changes 最多 20 条；整份 JSON 上限 6000 字符：先裁最旧历史，仍超限则**中止写入**（绝不写截断 JSON）。
- 兼容旧 v1 扁平 JSON 读取并迁移；同一图框存在多份记录时取更新时间最新的一份。

## 3. U1U 电缆预留

- 总长 = 图上实测长度 + 盘内预留 + 设备内预留。
- 盘内预留按上游类型：I-Line 盘 3400mm / 插座盘 1200mm / 母线插接口 500mm。
- 设备内预留不再走命令行：在 U1U 清单确认窗里填写（批量首次弹一次 GUI），确认后写入 frameinfo_json，后续 U1U 自动预填。
- CABLE_INFO 全部用 mm 标注：「分段=实测合计mm（盘内预留）+xxxmm（设备预留）+xxxmm=总长mm」；预留为 0 的段落省略。多行属性宽度固定 78300 自动换行。
- 图上没有实测电缆长度时不做预留（不凭预留凭空生成电缆清单）。

## 验证

- dotnet test：**1127/1127** 通过（新增电缆预留规则、v2 编解码、迁移顺序契约等用例）。

## 已知限制（需要现场确认）

- 批量 U1U 的设备内预留是「一个值应用到本批所有还没有记录的图框」；如果一批里混有不同机型、需要不同预留，暂时只能分批执行或用单框 U1U 单独改。
- 迁移移除 BRIDGE_FRAME_INFO / CONDUIT_INFO 后，图框上不再显示这两段旧文本（桥架/线管数据仍按统计重算，写入清单表与 BOQ）。如果仍需要在图框上显示，需在模板里把属性加回来。
