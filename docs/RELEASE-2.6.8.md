# UNCAD Pro 2.6.8

发布日期：2026-10-11

本版修 Downstream 规则里那一行 4.x 插座盘的**型号匹配**：现场反馈该行出现
`BOQ-CATALOG-MISSING`（"找不到对应型号：插座盘"）。

## 问题

2.6.7 引入的 Downstream 规则本身生效了（`socket box` 时确实多出一行 4.x 插座盘），
但那一行的额定电流仍然沿用 `U_配电信息` 提取出来的值（现场是 100A）。那是**盘柜主开关
电流**，与"插座箱"不是一回事：固定清单的 4.x 条目里没有 100A 这个规格，于是整行变成
未匹配、默认不勾选、项目编码为空。

## 修复

**下游 socket box 的 4.x 插座盘改用固定额定电流。**

- 新增设置 `U1SET → Excel 数据 → 下游插座箱额定电流（A）`，默认 **20**，范围 1–1000。
- 该规则生成的 4.x 行只用这个值匹配固定清单，不再解析 `U_配电信息`。
- 匹配不到时仍然输出一行交给用户在清单确认里处理（不猜型号，D-016）。
- 只影响 Downstream 规则生成的那一行：上游 `U_上游类型=插座盘` 的规则保持原样；
  **永不添加断路器**、不加 8.x 插座行等既有规则不变。

## 验证

- `dotnet test UNCAD.slnx`：1055 项全部通过。新增/更新：
  - 默认 20A 必须能在**真实内嵌固定清单**里匹配到插座盘条目（现场问题的直接回归）；
  - 把额定电流改成清单里没有的 999A → 变成未匹配行交给用户，而不是猜；
  - U1SET 新增字段存在且范围 1–1000（含 UI 布局契约测试）。
- 真机状态读取已在 2.6.7 用现场图纸 `插座箱.dwg`（59 个 Downstream 块全部 socket box）验证；
  本版只改那一行的取值来源，不涉及状态读取。
