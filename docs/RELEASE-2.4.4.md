# Release 2.4.4

## 清单与图框更新

- 修复 `U1F`、`U1U`、`U1S` 批量流程，CAD 表格和自动 BOQ 统一使用同一固定清单项目编码。
- 用户确认的替代型号、图框身份和变更历史写入 `frameinfo_json`，后续 `U1U` 会复用有效记录。
- 旧版图框与 `xframe` 继续兼容，迁移和更新保持用户现有表格尺寸不变。

## 排版与统计

- 强化 `XLAYOUT` 的图框身份读取及重复标记范围处理。
- `XSTS` 对未知机台、异常图框和多出回路给出明确统计结果。
- 改进 `Xmerge` 的同名块定义处理、批量导入和失败回滚。

## 发布校验

- 统一版本：`2.4.4` / `2.4.4.0`。
- 仅生成 `UNCAD Pro` 在线授权包；客户和到期信息继续由 `pro.key` 提供。
