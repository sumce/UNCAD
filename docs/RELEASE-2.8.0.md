# UNCAD Pro 2.8.0

发布日期：2026-10-26

本版在生成的 BOQ 工作簿里新增 **DATA 工作表**：一行一个回路，记录电缆、软管、
桥架、线管、上下游轴位与更新时间，便于按回路追溯数据来源。

## 新增

**1. DATA 工作表（与 BOQ 同文件）。**

BOQ 文件（`[BOQ]机台ID.xlsx`）在原有 `Sheet1` 之外多一个 **`DATA`** 表，列如下：

| 列 | 来源 |
| --- | --- |
| 更新时间 | 本次写入时间（`yyyy-MM-dd HH:mm:ss`） |
| 机台ID / 回路 / 盘类型 | 图框身份与盘类型 |
| 电缆型号 / 电缆长度(m) | 图框清单/设备块 |
| 软管管径 / 软管长度(m) | 软管规则 |
| 桥架信息 / 桥架长度(m) | 框选统计 |
| 线管信息 / 线管长度(m) | 框选统计 |
| 上游轴位 / 下游轴位 | 设备块轴位 |
| 材料行数 | 该回路写入 BOQ 的材料行数 |

**2. 更新语义与 BOQ 设备列一致。**

按「机台ID + 回路名」定位：**有则更新、无则追加**；同机台其它回路的行保留不动。
重复执行 U1F/U1U 只刷新对应那一行（含更新时间），不会累积重复行。

## 说明 / 不做

- **不改模板**：现有 `BOQ_Template.xlsx` 只有 `Sheet1`，DATA 表在写入时自动创建；
  用户已有的 BOQ 文件下次写入也会自动补上 DATA 表。
- DATA 表只**追加/更新**，不删除历史回路行（图框改名后旧行会保留，与 BOQ 设备列
  的现有行为一致）；需要清理时手工删行即可。
- 长度类字段在能解析为数字时写成**数值**（Excel 可直接求和），否则原样写文本。

## 验证

- `dotnet test UNCAD.slnx`：1065 项全部通过。新增
  `BoqDataSheetTests`（4 项）：表头与一行一回路、重复写入更新不追加、其它回路行保留、
  以及走真实 `BoqWorkbookWriter.Write` 的集成测试（目标文件里出现 DATA 表且数值落格）。
