# Release 2.4.1

## 机台数据与性能

- U1SET 的“刷新”是机台工作簿唯一的解析入口；支持本地和 HTTP/HTTPS 工作簿。
- 解析后的统一 `U_` 字段和普通 `回路名称` 写入每用户 SQLite 快照，命令执行时不检查源文件时间戳、不自动联网或重新解析。
- U1F、U1U、XSTS、XLAYOUT 按需查询快照，减少重复加载整本 Excel；源文件变化在下一次手动刷新后生效。
- 刷新过程采用事务和稳定性校验，解析或写入失败时保留上一份有效快照。

## 发布校验

- 统一版本：`2.4.1` / `2.4.1.0`。
- 仅生成 `UNCAD Pro` 在线授权包；客户和到期信息继续由 `pro.key` 提供。
- SQLite 快照默认位于 `%LOCALAPPDATA%\UNCAD\cache\machine-data.db`。
