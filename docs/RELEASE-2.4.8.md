# Release 2.4.8

## 桥架与标注

- 修复桥架 BOQ 两行 MTEXT 在格式码、额外空白和大小写差异下的识别与求和，长度行不再误计为电缆。
- 两行标注严格按“固定清单型号 + 纯长度”配对，孤立长度或带前缀的文本不会被误识别为桥架项目。
- 修复 `U1Q*` 在大坐标、多角度斜线下的端点、中点和偏移计算，批量标注稳定生成。

## Excel 兼容

- 统一机台表在前 51 个物理行内自动识别表头，兼容第二行表头。
- 固定清单生成脚本采用同一套表头识别规则，避免模板表头位置变化导致读取失败。

## 界面与发行包

- 修复 Windows 150%/200% 缩放及多显示器切换下窗口超出工作区、导航和列表尺寸未跟随 DPI 的问题。
- 移除未使用的 JSON 依赖，减少宿主加载冲突并缩小发行包。

## 发布校验

- 统一版本：`2.4.8` / `2.4.8.0`。
- 仅生成 `UNCAD Pro` 在线授权包；客户和到期信息继续由 `pro.key` 提供。
