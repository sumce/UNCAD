# UNCAD Pro 3.6.0

发布日期：2026-11-24

## 新增

### 同名回路全面兼容（D-057）

一个机台有两条同名回路（上游编号不同）时，XSTS / XLAYOUT / 清单 / PDF / DWG
不再把它们当成一条。统一配对规则：图框按回路身份键（机台ID + 回路名 + 上游
编号）与台账一一配对；回路名在机台内唯一才按名配对；同名回路不按名猜。

- **XSTS**：应有个数不塌缩；合法的同名回路不再误报「图框重复」；只画一条能
  正确判缺（缺项带上游编号）。机台表新增「重复图框」「待确认」两列，图框明细
  新增「上游编号」列；窗口行高 32→26，底部详情条随选中行列出已选 / 缺少 /
  多出 / 待确认回路的全量名单。
- **XLAYOUT**：同名回路不再画黄色「重复」框，只框真正多出来的那张；按上游排版
  时各归各的上游行、行序各按自己的 Excel 行；图框没记录上游编号的同名回路归
  「同名回路待确认」行。统计窗改密排 9 列 + 选中机台全量回路名单 + 图框明细
  （双击定位到图框）；选择树叶子带上游编号与图框句柄，筛选框认上游编号；结果
  导出与清单导入加「上游编号」列，同名回路只排一部分记「不全」。
- **清单（BOQ）**：同名回路各占一列（列名「回路名（上游 X）」），不再合并相加；
  DATA 页各占一行并新增「上游编号」列。旧清单里被合并的那一列由第一条同名
  回路接管改名，不留重复列。
- **U1PDF**：机台内有同名回路时文件名带上上游编号
  （`<机台>_<回路>_<上游>.pdf`），重出其中一条不再顶掉另一条。
- **U1DWG**：选择窗回路计数按回路身份去重。
- **U1F**：机台选择窗新增「上游编号」「厂务开关」列，行高 34→26；同名回路在
  「设备 / 回路」上带上游后缀。

### 制图信息表内容可配（D-057）

图框内小表（专业 / 楼层 / 制图 / 审核 / 日期 / 版本）六列内容由 U1SET 新页
「图框与排版」决定。每一列可以写固定文字，也可以夹占位符（全角 / 半角括号
均可，页面上的按钮点一下插入）：

`(机台ID) (区域) (回路名称) (批次) (序号) (上游编号) (设备楼层) (上游楼层)
(楼层) (设备轴位) (上游轴位) (厂务开关) (上游类型) (电缆型号) (配电信息)
(日期) (时间) (U1F创建时间) (U1U更新时间) (更新时间) (用户)`

时间类可以带格式，例如 `(U1U更新时间:yyyy-MM-dd HH:mm)`。**留空 = 不改这一格**
——图框里现有的内容保留，可以直接在图框里手工改。默认模板与之前完全一致
（楼层 = 设备楼层/上游楼层、日期 = 运行当天，其余不动）。

为此 frameinfo_json 新增创建时间（最近一次 U1F）与最近一次写入的命令；老图框
首次 U1U 时把原来的更新时间当创建时间沿用。

### 更多可配置项（D-057）

- 清单（BOQ）标题三行：留空用清单模板里的文字；占位符 `(机台ID) (日期)
  (时间) (用户)`。
- XLAYOUT 排版参数：图框间距、机台标签字高、标签离图框距离、是否给重复 /
  待确认图框画黄色提示框。默认值即旧常量，越界或填错自动回落默认。

### XLAYOUT 算法审查结论（随本版修正）

- 按完整性排行用的是「全图」的就绪度，而标签颜色用的是「本次参与集」——取消
  勾选几条回路后行序与颜色对不上。现统一取本次参与集。
- 上游模式下一行跨多台机台，行标签颜色取的是行内最左图框的机台，颜色随图框
  位置随机。现取整行最差的机台。
- 同一上游的不同写法（带槽位 / 轴位标注）会排成两行。现按去掉标注的编号归行。
- 同一个 SQLite 快照一次命令里读了三遍。现读一次共用。

## 明确不做

- 不迁移、不重写老图框的 frameinfo_json；同名回路且没有上游编号的图框需要
  跑一次 U1F / U1U 指认。
- 不改清单文件名、图纸文件名规则；没有同名回路的机台，输出文件与 3.5.0 相同
  （XSTS 新增列除外）。
