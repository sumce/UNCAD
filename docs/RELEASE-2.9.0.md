# UNCAD Pro 2.9.0

发布日期：2026-10-29

本版升级 **XLAYOUT（图框自动排版）**：框选图框后先弹出"机台/回路选择"窗口，
可以按机台展开回路、勾选、并用关键词筛选，**只对选中的回路重排**，其余图框保持原位。

## 新增

**1. 排版前的机台/回路选择窗。**

- 两级树：**机台 → 回路**，两级都带复选框；勾选机台节点会同时勾选它的全部回路，
  取消任一回路则机台节点自动取消。
- 顶部**筛选框**：用空格、半角/全角逗号、分号、顿号或竖线分隔多个关键词，
  **任一关键词命中即保留**（OR 语义，与 Excel 多选筛选一致，可整段粘贴机台ID）；
  匹配范围是"机台ID + 回路名称"，忽略大小写。例如：
  - `MQBAN03` → 只显示该机台
  - `MCWCE01 MDHCV02,MYDFI15，MYOMI02` → 只显示列出的这些机台（空格/中英文逗号都可）
  - `电脑` → 显示所有含"电脑"的回路
- 输入停顿 250ms 才重建列表（大图纸 1000+ 回路不卡）；筛选无结果时给出提示节点。
- **只重排"勾选且命中当前筛选"的回路**；未勾选或未命中的图框完全不动。
- 全选 / 全不选 / 反选只作用于**当前筛选可见**的回路；另有 展开全部 / 折叠全部。
- 底部状态行实时显示：`共 N 个回路，筛选命中 M 个；将重排 K 个`。

**2. 与统计/标签保持一致。**

  - 机台标签颜色、"排版完成"统计窗只反映**本次实际重排**的回路子集；
  - 若只排了某机台的部分回路，相对于台账"应有回路"仍会提示**缺少回路**（正确信号）。

## 说明 / 不做

- 选中图框 ≤ 1 时不弹窗，直接排版（与以前一致）。
- 弹窗里点"取消"= 不排版、图纸不动；**默认全部勾选**，所以不筛选直接确定与旧行为相同。
- 2.9.0.1 修订：多个关键词由"全部命中（AND）"改为"任一命中（OR）"——此前粘一串
  机台 ID 时，只要有一个词对不上就 0 命中、列表全空；现在与 Excel 多选筛选一致。

## 2.9.0.2 修复：批量 U1U 图框很多时可能长时间卡住

- **场景构建 O(N²)**：上传等轴测场景时每个图框都调一次 `CollectForLayout`（全空间扫描）。
  现在复用分区阶段已算好的图框区域，整批只扫一次。
- **每框多余事务**：预检后每个图框又各开一个事务重算表格容量；改为预检读事务内一次算好。
- **无进度反馈**：批量预检 / 写入图纸 / BOQ 逐机台输出 / 回路上传都加了进度提示与界面刷新。
- **内存风险**：场景单个上限 1,000,000 字符，上千个一次性构建可到上百 MB；现在整批
  设 64MB 预算，超出的回路只上传清单、跳过场景，并在命令行汇总提示。

## 2.9.0.3 修复：批量 U1U 上传把线程池/内存打爆（内存 5GB、CPU 仅 10%）

日志证据：每个回路的上传间隔 **7~11 秒**（网络超时 / HTTP 302 / 域名解析失败），而批量会为
上千个回路**各排一个 ThreadPool 任务**；阻塞的 HTTP 任务让线程池不断注入新线程（每个 1MB 栈），
每个任务还持有清单与场景字符串 → 内存冲到 GB 级、CPU 却很低、进度慢如卡死。

- 上传改为**单线程串行队列**（`BackgroundUploadQueue`）：同一时刻只有一个请求在飞；
- 队列**有上限（64）**：队列满或已熔断时，连等轴测场景都不构建，直接跳过该回路上传；
- **连续 3 次失败自动熔断**：丢弃剩余排队项并只记一条日志，命令行汇总"上传已暂停/丢弃 N 项"；
  图纸与 BOQ 完全不受影响，网络恢复后重跑 `U1S` 可补报；
- 新增 4 项队列单测（顺序执行、上限拒绝、连续失败熔断并丢弃、成功重置失败计数）。

## 2.9.0.4 修复：批量 U1U 每个图框都扫全图（又一处 O(N²)）

日志证据：236 个图框的批量，**每帧场景构建 5~7 秒**（且这些帧根本没有 U1L 线段），整批 20 分钟。

- `BuildRegionEnvelope` 里的 `QuickLineCadService.Scan` **不带图框过滤、扫的是整个空间**，
  逐框调用即 O(N²)；现在批量侧用 `SceneScanCache` **整批只扫一次**，再按图框过滤；
- "上传已熔断/队列已满"的判断原来放在场景构建**之后**，导致熔断后仍然逐框白扫；
  现在提前到构建之前，熔断后整段立即快进；
- 契约测试补了 4 条断言锁住"整批一次扫描"，防止回退。
- 不会因为筛选而移动未命中的图框，也不会删除/新增图框。
- 旧图纸兼容：只影响排版前的选择环节，排版算法（每机台一行、左对齐、间距 10000）不变。
