# UNCAD Pro 2.9.0

发布日期：2026-10-29

本版升级 **XLAYOUT（图框自动排版）**：框选图框后先弹出"机台/回路选择"窗口，
可以按机台展开回路、勾选、并用关键词筛选，**只对选中的回路重排**，其余图框保持原位。

## 新增

**1. 排版前的机台/回路选择窗。**

- 两级树：**机台 → 回路**，两级都带复选框；勾选机台节点会同时勾选它的全部回路，
  取消任一回路则机台节点自动取消。
- 顶部**筛选框**：用空格、半角/全角逗号、分号、顿号或竖线分隔多个关键词，
  **任一关键词命中即保留**（OR 语义，与 Excel 多选筛选一致，可整段粘贴机台ID）；
  匹配范围是"机台ID + 回路名称"，忽略大小写。例如：
  - `MQBAN03` → 只显示该机台
  - `MCWCE01 MDHCV02,MYDFI15，MYOMI02` → 只显示列出的这些机台（空格/中英文逗号都可）
  - `电脑` → 显示所有含"电脑"的回路
- 输入停顿 250ms 才重建列表（大图纸 1000+ 回路不卡）；筛选无结果时给出提示节点。
- **只重排"勾选且命中当前筛选"的回路**；未勾选或未命中的图框完全不动。
- 全选 / 全不选 / 反选只作用于**当前筛选可见**的回路；另有 展开全部 / 折叠全部。
- 底部状态行实时显示：`共 N 个回路，筛选命中 M 个；将重排 K 个`。

**2. 与统计/标签保持一致。**

  - 机台标签颜色、"排版完成"统计窗只反映**本次实际重排**的回路子集；
  - 若只排了某机台的部分回路，相对于台账"应有回路"仍会提示**缺少回路**（正确信号）。

## 说明 / 不做

- 选中图框 ≤ 1 时不弹窗，直接排版（与以前一致）。
- 弹窗里点"取消"= 不排版、图纸不动；**默认全部勾选**，所以不筛选直接确定与旧行为相同。
- 2.9.0.1 修订：多个关键词由"全部命中（AND）"改为"任一命中（OR）"——此前粘一串
  机台 ID 时，只要有一个词对不上就 0 命中、列表全空；现在与 Excel 多选筛选一致。
- 不会因为筛选而移动未命中的图框，也不会删除/新增图框。
- 旧图纸兼容：只影响排版前的选择环节，排版算法（每机台一行、左对齐、间距 10000）不变。

## 验证

- `dotnet test UNCAD.slnx`：**1083/1083** 通过。新增 18 项：
  - `XLayoutSelectionFilterTests`（14 项）：空格/逗号/中文逗号/分号/顿号分隔、
    AND 语义、大小写不敏感、机台与回路名的匹配范围、空筛选命中全部；
  - `XLayoutSelectionFormTests`（4 项）：两级树与默认全选、筛选只收窄可见集、
    勾选只作用于可见项且在切换筛选后保持、机台节点与其回路的勾选联动。
