# UNCAD Pro 2.6.7

发布日期：2026-10-11

本版在 2.6.6 之上新增**下游端 `Downstream` 块**支持（业务规则来自现场：有些图纸的
下游端不是 `Device_Build20260716`，而是 `Downstream` 块）。

## 新增

**1. 识别 `Downstream` 块（精确块名）。**

块名精确等于 `Downstream`（含 Xmerge 重命名后的 `Downstream$0$`）即认；刻意不做前缀或
模糊匹配——`DS` 轴位块、`upstream` 块都不会被卷进来。

**2. 三态与 `upstream` 完全一致，按设备侧颜色上色。**

`Downstream` 与 `upstream` 共用同一套可见性状态：`I-line_Panel` / `socket box` /
`busbar connector`。它在图纸上属于下游/设备端，因此按**设备侧颜色**归一化。

**3. `socket box` 时额外加一套 4.x 插座箱/插座盘。**

在上游规则产生的行之外**再加一行** 4.x 插座箱/插座盘（`TableFillCategory.OutletPanel`），
受 U1SET 的**“插座盘”自动填充开关**控制（默认关闭）。

## 明确不做（防止"顺手补齐"）

- **不加 8.x 插座行**：那条由 `Device_Build20260716` 的状态负责，不重复。
- **永不添加断路器**：断路器只由上游 `U_上游类型 = I-Line盘` 产生。
  `Downstream` 的 `I-line_Panel` / `busbar connector` 两态**只影响颜色**，不产生任何清单项。
- 同一图框内多个 `Downstream` 状态冲突（一个 socket box、一个其它）时**中止本次填充并提示**，
  不猜测；状态读不出来时不影响其它清单项。

## 影响面

- `U1F` 与 `U1U`（含批量）都会生效；生效点在评审窗口之前，所以用户能在清单确认里看到、
  也可以删掉这一行（删除是持久决定，不会在写表前被重新加回）。
- 命令行会打印 `Downstream 状态: … ；插座箱清单: 额外输出一套/不输出`，便于现场核对。

## 验证

- `dotnet test UNCAD.slnx`：1054 项全部通过（本版新增 18 项针对 Downstream 规则的测试：
  精确块名匹配、三态判定、只加一行 4.x、受开关控制、**断言永不加断路器**）。
- **真机验收待补**：现有 CAD 自检无法程序化创建带可见性状态的动态块定义，因此这条规则
  没有真机自检覆盖。已请用户提供一张带 `Downstream` 块的真实图纸做专项验收
  （预期：`socket box` 时多一行 4.x 插座箱；`I-line_Panel` 时只变色、不加断路器）。
