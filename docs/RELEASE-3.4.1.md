# UNCAD Pro 3.4.1

本机构建日期：2026-11-19（UTC+8，构建元数据日期为 2026-11-18 UTC）。

版本：`3.4.1.6`。本地正式 tag `v3.4.1` 和 ZIP 已生成；ZIP 未上传服务器。
本机安装目录程序集版本为 `3.4.1.6`，但其 bundle 校验清单与本次重建不同，
未覆盖安装。用户实际图纸验收仍待完成。

## 新增

- `XSTS` 窗口和 Excel 新增“图框明细”：逐项输出实际图框清单的
  机台 ID、回路名称、图框 ID、清单序号、项目名称、规格/型号（项目特征）、
  单位、数量、编码。
- 电缆、桥架、线管、软管、盘箱、断路器和自填项目均保留，不按材料类别
  或固定清单编码过滤。空值、零值、非数字数量、多行特征和原始编码保持原样。
- 图框 ID 使用当前 CAD 句柄并按文本保留前导零；空清单、重复图框和异常
  图框保留定位行，异常列表同样显示图框 ID。
- 窗口与 Excel 冻结前三列；Excel 支持自动筛选、换行和冻结表头。

## 移除与修复

- 删除“近名提示”和“未上图机台”的页面、导出表、徽章及额外全图扫描。
- 保留选中机台的缺少/多出回路对比；无基准或存在异常时不再提示回路齐全。
- 分别显示图框数与机台数。

## 3.4.1.2 三维轴号与交互、路线扫描优化

- 轴号以完整组合（如 `48/AA`）显示在柱位，支持多字母轴号；轴位区域
  中心与柱网交点一致，回路长度和上下游区域匹配规则保持不变。
- WebV 补齐“柱子”开关；柱子隐藏后保留轴号，WPF 切换图框保留显隐选择。
- WPF 避免重复建模，隐藏结构首次开启才建网格，拖动更新合并到渲染帧；
  两种预览均支持中键平移和鼠标位置缩放，复位恢复角度、位置及缩放。
- 路线配对使用空间索引筛候选，评分和全图归属顺序保持不变；图框范围
  筛选位于归属完成后，避免抢走框外近邻线的毫米标。
- 已通过 CAD 合成场景检查：3000 条框外路线、跨框标注竞争、框外明确关联
  标注、合并线旧标恢复、活句柄保护、软管排除，以及索引与原评分的候选
  一致性。此次全图扫描 317ms，限定返回范围 204ms；优化前同规模约 1637ms。
  这是本机合成图计时，未验证用户实际大图的 U1U 总耗时。
- WebV 在 1280×800 和 390×844 视口通过真实 canvas 像素、柱子显隐、完整轴号、
  柱位投影（误差小于 1px）、旋转、平移、缩放和复位检查。
- 最终验证：`dotnet test UNCAD.slnx --no-restore` 1634/1634 通过，0 跳过；
  Release 产物定向测试 88/88 通过；`UNCAD_SCOPED_SCAN_SELFTEST`、
  `UNCAD_ROUTE_INSPECT_SELFTEST`、`UNCAD_PERFORMANCE_SELFTEST` 均通过。
  WPF 合成场景首次装载 342ms，同一模型重复设置 100 次合计小于 1ms。
- `build.ps1 -NoRestore`、`installer.ps1 -Mode VerifyPackage` 成功，
  26 个安装文件通过校验，构建输出与 bundle 的主 DLL 版本和 SHA-256 一致。

## 3.4.1.4 桥架与线管长度格式

- 图框属性里的桥架、线管长度统一使用毫米：单段只显示长度，例如
  `4000mm`；两段及以上显示各段相加和合计，例如
  `2000 +2500 = 4500mm`。
- 旧图框若仍有 `CONDUIT_INFO`，也使用相同的毫米格式。BOQ 工程量及统计
  报表单位不变。
- 定向图框填充测试通过 56/56。尚未安装、未出包；实际图纸验收待进行。

## 3.4.1.5 INFO2 展示修正

- `INFO2` 仅展示桥架和刚性线管；线管型号简写为 `镀锌穿线管38mm`，
