## 3.4.1.11 XLAYOUT 布局身份不读设备块 + 失败反馈与日志

- **XLAYOUT 身份只读图框自身属性（D-045 修订）**：机台/设备名一律取自图框的
  `MACHINEID-POWER`/`MACHINEID-DEVICE` 属性（及 FRAMEINFO JSON，仲裁语义不变），
  设备块 `DEVICENAME` 不再参与，也不再有「图框属性与设备块不一致」的布局中止。
  背景（现场 2026-11-22，「(A1)全部图纸」2204 框全图执行）：MTPWM04 的 8 个
  图框全图执行时报与设备块 `Hot DIW-1`/`LP` 不一致并整体中止，单选同机台
  17 框却正常——设备块按插入点归属分区，全图/单机两种选择的边界集不同，
  归属结果随之漂移。身份与选择集解耦后两种选择读出同一身份。
  U1S/U1F/U1U 的 DEVICENAME 硬校验不变（它们要匹配 Excel 回路）。
- 图框识别或身份异常会在 WPF 诊断窗完整列出，不再只在 CAD 命令行展示前
  20 条；诊断可复制，文件日志写入全部异常，操作记录标记为 `FAILED`。
- U1S/U1F/U1U 的身份冲突诊断（`DEVICENAME` 候选块的句柄、块名、插入点、
  几何中心、属性位置和实际取值来源——实例属性/动态属性/块定义默认值）
  保留在共享读取路径上，便于区分空间归属错误与属性读取回退。
- XLAYOUT 的取消路径记录为 `CANCELLED`；异常堆栈写入文件日志。机台/回路
  选择与点位提示仍由 AutoCAD 命令行负责，业务状态与成功结果由 WPF 窗口展示。
- 操作记录补入已识别的机台/回路；已在目标位置而跳过的图框数量显示在成功统计窗。
- 验证：XLAYOUT 身份诊断定向测试通过（63/63）；全量
  `dotnet test UNCAD.slnx --no-restore` 通过 1666/1666。

## 3.4.1.10 可选毫米标归位

- U1SET「绘制标注」新增默认关闭的 U1F/U1U 毫米标位置与角度矫正开关。
- 开启后仅归位带 U1L 关联的毫米标，按当前文字位置/偏移设置贴合线段；
  不改文字内容、字高、桥架或线管。旧图纸相邻标注的角度识别容差放宽到 15°。
- 修正随 U1F/U1U 图纸事务提交或回滚；U1R 元数据重挂和唯一近邻的合并直线标注恢复规则不变。

## 3.4.1.9 CABLE_INFO 电缆前缀

- 新写入的 `CABLE_INFO` 在型号前显示 `电缆 `，例如
  `电缆 ZB-YJVR-3*2.5mm²`；无长度统计时格式一致。
- U1U 回读、设备预留恢复和提交记录提取继续兼容旧格式；BOQ 型号匹配不变。
- 验证：电缆格式和回读定向测试 69/69 通过；全量
  `dotnet test UNCAD.slnx --no-restore` 测试 1658/1658 通过。

## 3.4.1.8 U1F 停止自动矫正

- U1F 不再按 U1SET 改写 U1L 毫米标、U1Q 桥架和 U1C 线管的文字大小、
  线距或样式，也不再迁移旧桥架标注；U1B 软管文字高度矫正和图层归位保留。
- U1U 吸收设备预留后会确认标记文字已删除。删除失败会中止并回滚整次
  填充，避免预留值已写入但原文字仍留在图框内。
- 验证：`dotnet test UNCAD.slnx --no-restore` 1656/1656 通过；
  `UNCAD_MARKER_SELFTEST` 在出厂图框模板副本通过；AutoCAD Release 集成项目
  编译 0 警告、0 错误。

## 3.4.1.7 U1U 停止自动矫正

- U1U 更新不再改写 U1L 毫米标、桥架和线管的文字大小、线距或样式，也不再
  迁移旧桥架标注；U1F 重新定义模式保留原矫正和迁移行为。
- U1B 软管文字高度矫正及 U1U/U1F 图层归位保持不变。
- 验证：Release 全量测试 1655/1655 通过；AutoCAD 性能冒烟、图框迁移自检及
  26 个发布包文件 SHA-256 校验通过。

## 新增

- `XSTS` 窗口和 Excel 新增“图框明细”：逐项输出实际图框清单的
  机台 ID、回路名称、图框 ID、清单序号、项目名称、规格/型号（项目特征）、
  单位、数量、编码。
- 电缆、桥架、线管、软管、盘箱、断路器和自填项目均保留，不按材料类别
  或固定清单编码过滤。空值、零值、非数字数量、多行特征和原始编码保持原样。
- 图框 ID 使用当前 CAD 句柄并按文本保留前导零；空清单、重复图框和异常
  图框保留定位行，异常列表同样显示图框 ID。
- 窗口与 Excel 冻结前三列；Excel 支持自动筛选、换行和冻结表头。

## 移除与修复

- 删除“近名提示”和“未上图机台”的页面、导出表、徽章及额外全图扫描。
- 保留选中机台的缺少/多出回路对比；无基准或存在异常时不再提示回路齐全。
- 分别显示图框数与机台数。

## 3.4.1.4 桥架与线管长度格式

- 图框属性里的桥架、线管长度统一使用毫米：单段只显示长度，例如
  `4000mm`；两段及以上显示各段相加和合计，例如
  `2000 +2500 = 4500mm`。
- 旧图框若仍有 `CONDUIT_INFO`，也使用相同的毫米格式。BOQ 工程量及统计
  报表单位不变。
