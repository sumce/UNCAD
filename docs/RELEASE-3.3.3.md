# UNCAD Pro 3.3.3

发布日期：2026-11-17

## 新增

**U1B 绘制软管**（D-054 Amendment，feature 版；用户原话：「绘制软管 输入 U1B
然后让用户 自己来用类似 LINE 的方案来连线(支持多段) 回车后 用线条绘制一个
平面的管子 管子直径默认100 绿色 然后要求用户鼠标点击一个位置 点击后
自动将这个多段线的中点连向这个位置并生成文本 软管xxxxxxx 注意需要
处理好拐弯处 和首尾端」）。

- **交互同 LINE**：连续取点（橡皮筋跟随上一点；`U` 回退上一点，回退到空时
  重新要起点；回车/空格结束取点；重复点自动忽略；ESC 取消时未画任何实体）。
  至少 2 点才绘制，不足礼貌退出不画图。
- **管子几何**（Core 新增 `HoseOutlinePlanner`，解析式、纯单测逐值锁死）：
  中心线两侧偏移 ±直径/2 的双线轮廓（不用 LWPolyline ConstantWidth，管壁
  是真实轮廓线）；**拐弯处**外侧用半径=管半径的圆弧过渡（切点即偏移端点，
  天然相切）、内侧用偏移线交点截断（近折返的病态急弯交点射远时退化为
  bevel 直连——有界不炸，与 U1Q 的 `OffsetPolylineBuilder` 同哲学）；**首尾
  半圆端帽**封口。共线连续点/重复点自动清理。输出一条**闭合 LWPolyline**，
  夹持编辑不散架；中心线本体不保留。
- **默认直径 100**（新配置 `UNC_HOSE_DIAMETER`，U1SET 绘制标注页可改），
  绿色 ACI 3，新法定图层 **U_HOSE**（全大写家族，色号 3 绿）——
  `UncadLayerStandard` 法定图层第四名，图层矫正报告文案同步加「软管 h」项。
- **标注**：管子生成后提示点取标注位置（橡皮筋自路径**长度中点**），从该
  中点拉细引线到点击点，生成单行文字（高度沿用 UNL_HEIGHT）。默认文字
  沿用软管链路既有格式 `100mm软管:2500mm`（U1C/U1F/U1U 写进 Ruanguan 块的
  就是这个格式，长度取整到 10），提示时可改。该格式整行不匹配电缆/桥架/
  线管求和判据、也匹配不上 D-043 设备预留标——不污染统计、不被误吸收；
  软管米数统计仍以 Ruanguan 软管块为准。
- **归属与扫描**：管子/引线/文字全部挂 `ParallelAnnotationMetadata`
  KIND=`U1B`——图层矫正链自动认得（U1B→U_HOSE）；扫描器与 U1Q/U1C 同口径
  （TryRead 命中即跳过），管子轮廓/引线绝不会被当成电缆路由。
- **一个事务**：全程一个写事务，一次 U 连同管子/引线/文字整体撤销。

## 验证

- dotnet test UNCAD.slnx --no-restore：全部通过。
- UNCAD_HOSE_SELFTEST（accoreconsole 真机）：L 形路径直调生产几何服务，
  断言闭合轮廓 7 顶点（两端帽 |bulge|=1 + 外拐角弧 tan(π/8) + 内 miter）、
  图层=U_HOSE（色号 3）、三实体 KIND=U1B、引线起点=长度中点、默认文字
  格式、Scan 不认它当电缆、退化路径拒绝。
- UNCAD_MIGRATION_SELFTEST PASS、UNCAD_ROUTE_INSPECT_SELFTEST DONE（无回归）。
