# UNCAD Pro 3.7.0

发布日期：2026-11-25

## 新增

### U1U 的 3D 路由预览重新可用（D-058）

3.4.1 起，U1U 确认窗左侧的 3D 一直是没有数据的（数据链被摘掉，窗口和渲染
器都还在）。这次把数据链重建了：单框清单确认窗和批量确认窗的左半仍是 3D，
布局不变；U1F 仍然不建预览。

- **按毫米标重建线路**：图框里带毫米标的线段重建成 X/Y/Z 三维路线（长度取
  毫米标），每段标出毫米数。
- **断口容差**：两端都带毫米标、端点相距不超过容差的线段接成一条路线——
  「看着连着、放大才看出有缝」的断口不再把路线拆成几截。容差在 U1SET
  「图框与排版」页改（图纸单位，默认 50，0 = 只用严格容差，上限 500）。
- **桥架 / 线管**：U1Q / U1C 的输出按归属显示在对应的电缆段上（红双线带填充
  = 桥架并按标注宽度画，青双线 = 线管）。没有归属元数据的桥架/线管文字，
  就近绑定到旁边平行的带毫米标线段（只算这一段，并在问题里注明）。
- **软管**：取 Ruanguan 软管块的长度（图框里没有块时取 U1B 标注文字），在
  预览里从设备端沿末段方向示意画出（绿管）。只是示意，不写图纸、不进统计。
- **上游端 / 设备端**：离上游块最近的路线末端是上游端（琥珀球），离设备块
  最近的是设备端（绿球）；只有一个块时另一端取两端点路线的另一头；两个
  块都定位不到才按工作簿轴位推断。定不下来时在预览里说明原因，不猜。
- **识别摘要与问题点名**（预览底部、命令行、批量结果窗备注）：
  - 没有毫米标的线段（列出句柄）——是电缆线请用 U1LX 补标；
  - 被容差接上的断口（哪两段、间隙多大）；
  - 找不到宿主线段的桥架/线管标注（源线被删除或合并）；
  - 方向不是等测轴方向、进不了 3D 的线段。

连通性报告同口径：断口接上后显示「✔ N 段一条链（容错接上 K 处断口）」。
U13D 多图框预览用同一套断口容差。

### U1UL 毫米标归位（D-058）

新命令，Ribbon「标注」面板里叫「毫米标归位」。把毫米标**离线的距离**归到
U1SET 的偏移值、**角度**改成与线段平行：

- 毫米标现在在哪一侧就留在哪一侧——手动挪到另一侧的不挪回去；
- 沿线方向的位置也保持，不拉回中点；
- 只动带 U1L/U1LX 关联的毫米标；旧图纸里只靠位置匹配到的毫米标不动，
  它所在的线段会点名列出；
- 不改文字、不改字高；一个事务，一次 U 整体撤销；
- 选图框 = 处理整框；选线段或毫米标 = 只处理它们。

## 明确不做

- U1LX 逐段填写和 Xauto 重排不变，仍用严格容差（它们会改动几何）。
- 图层矫正不变：仍然不按文字/颜色猜，只认元数据。
- 预览识别只读：不改图纸，不进 BOQ 和任何统计。
- 没有毫米标的线段不参与断口容差，也不进 3D。
