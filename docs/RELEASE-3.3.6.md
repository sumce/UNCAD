# UNCAD Pro 3.3.6

发布日期：2026-11-18

## 新增：U1U 3D 预览参照层（D-054 Amendment）

用户提供的建筑标高链与设备高度画进 3D 预览页——琥珀色水平参照框横贯场景
+ 边角标签（「2F地面 7800」「第三层母线 4900」…），供电缆爬升高度对照；
「参照 开/关」按钮，图例补「黄=标高参照」。

- **默认 12 条**（用户本单数值；楼层链累计折算）：1F工字钢顶面 2850、
  2F地面 7800、2F工字钢顶面 11000、2F葡萄架顶面 13300、3F地面 15000、
  3F高架地板面 15600、I-L盘顶面 2200、插座盘顶面 1000、第一/二/三层母线
  3660/4220/4900、插座盘安装 1000。
- **U1SET 可改**：`UNC_PREVIEW_REF_LEVELS`（绘制标注页新卡），格式
  「标签=毫米」分号/换行分隔；非法条目跳过；清空=不画。高度相对场景地面
  （最低线段端点=0）。
- 分层不变：Core 纯函数解析 → 信封携带 → 页面哑渲染（可整组开关）。

## 锁死与验证

- `PreviewReferenceLevelsTests` 6 条（默认表/累计标高逐值/容错/信封/契约键）。
- SettingsWindow 冻结键集 54→55。
- 浏览器端到端实测三轮视觉迭代（框线加粗 0.9 档、标签外推避让端点钉），
  终验确认 6+ 层参照框清晰、无重叠、零控制台报错。
- 全量 1583/1583（基线 1577）。
