# UNCAD v1.9.7.16 U1S 当前图框只读提交

- U1S 从配置中心改为 BOQ 提交命令，支持一个或多个 frame_20260812 图框。
- 提交信息全部来自当前 CAD：图框机台ID、设备名，以及清单项目编码、名称、单位和当前数量；M 单位的电缆、桥架、线管和软管米数原样提交。
- U1S 不读取或校验机台数据 Excel，不开启 CAD 写事务，不修改清单、块属性或动态状态。
- 配置中心迁移到 U1SET，所有设置提示和 Ribbon 入口同步迁移。
- U1F/U1U 现有更新算法及自动 BOQ 同步保持不变。
- 正式版和临时授权版分别发布；临时版到期时间仍为 2026-09-08 23:59:59 UTC+8。
