# UNCAD Pro 2.4.9

发布日期：2026-09-20

## 变更

- 机台 ID 与设备名称匹配统一忽略大小写、Unicode 空白及文本内部空格，兼容 `M Q-01`/`MQ-01`、`设备 A`/`设备A` 等输入差异。
- 图框、Excel 快照、XSTS、XLAYOUT、DWG 导出、U1S/自动提交和 BOQ 分组共用同一身份匹配规则。
- 匹配规范化只用于比较；原始文本仍用于显示、写回和持久化。
- 图框属性与设备块属性的机台/设备身份不一致时停止并提示，不再静默采用设备块名称。

- 受影响专项测试：53/53 通过。
- 全量测试：793/793 通过。
- `dotnet build UNCAD.slnx --no-restore`：0 错误、0 警告。
