# UNCAD Pro 2.6.5

发布日期：2026-10-11

## 加固：U1PDF 出图不可能改到用户的打印设置

2.6.2 已把 U1PDF 的**失败路径**改成不提交事务（靠回滚丢弃临时设备/纸张/旋转）。
本版把**成功路径**也补上同样的保证：

1. 出图结束后先逐字段还原用户的布局打印设置；
2. **全部还原成功** → 提交（图纸内容与出图前完全一致）；
3. **只要有一步没还原成功** → 整个事务回滚，用户设置由回滚保证原样。

回滚只丢弃对布局的临时改动：PDF 已经出好，照常进入上传队列，不影响出图结果与网页预览。

## 为什么敢这么做

"不提交就等于回滚"是这条保证的前提。之前只是假定，现在有真机证据：

- 新增探针 `UNCAD_TXPROBE`（AutoCAD 2022 core console）：
  - A 改了之后不 `Commit` 直接 `Dispose` → **回滚**；
  - B 显式 `Abort` → **回滚**；
  - C 显式 `Commit` → **落盘**（对照组，避免"什么都没变"的假通过）。
- 结论写进 `docs/DEVELOPMENT.md` 的真机自检清单，后续改动可随时复核。

## 其它

- `UNCAD.csproj` 的 `InformationalVersion` 之前停在 `2.6.1`（2.6.2–2.6.4 只改了三处版本号），
  本版统一到 `2.6.5`，避免构建元数据与实际版本不一致。

## 验证

- 全量单元测试通过（新增收尾策略用例：还原干净才提交、不干净必须回滚、提交点唯一）。
- 真机自检：`UNCAD_U1PDF_SELFTEST`（A3 幅面、彩色矢量、出图前后布局打印设置逐字段一致）、
  `UNCAD_U1DWG_SELFTEST`、`UNCAD_U1Q_SELFTEST`、`UNCAD_TABLE_FILL_SELFTEST`、
  `UNCAD_RUANGUAN_GW_SELFTEST` 全部 PASS。
