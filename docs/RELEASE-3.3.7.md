# UNCAD Pro 3.3.7

发布日期：2026-11-18

## 新增：U1U 3D 预览参照物升级为简化建筑模型（D-054 Amendment）

用户看过 3.3.6 的水平线框后明确要求「做一个模型 包括每层的地面」，
三轮口径迭代成型：

- **每层地面**：2F=环氧地坪（绿色泽面）、3F=华夫板（**真圆孔穿透**，
  每 4 个柱位围成的格间里 3×3 共 9 孔）、1F 地面在场景零平面自动铺板。
- **结构**：工字钢梁阵（1F/2F 顶面）、葡萄架格栅、3F 高架地板薄板、
  **柱网交点落地结构柱**（U1L 柱网 ≈4.8m 柱位，通到最高参照层）。
  **钢梁/葡萄架默认隐藏**——新「结构 开/关」按钮按需展开（三轮口径）。
- **空间推算**：不再贴着回路画 6% 边距——回路占位扩到**整跨柱网**、
  每侧再外扩一跨（无柱网退化为边距兜底）。
- **本层重定位**：新指令行 `本层=2F地面`——机台在几楼，那层地面就是
  场景 0（上游就在本层）；整栋楼按本层重画（3F=7200、1F=-7800 等，
  标签显示本层起算高度）。设备/母线高度本来就是本层地面起算——
  第四段锚定 `第一层母线=3660=母线=2F地面`。
- **母线三层**：半透明琥珀玻璃层横贯场景（3.66/4.22/4.9m 悬在本层
  地面上方，告诉用户这个高度是第几层母线）。
- **设备**：I-L 盘/插座盘沿底边排开的实体盒（锚定本层，高度准确、
  位置示意）。
- 光照（Lambert/Phong+双灯）+ 轻雾；「参照 开/关」整组开关、「结构
  开/关」细节开关、图例按实际类型标注。
- 顺手修复：3.3.5 起每帧标签刷新会把柱网/参照开关隐藏的标签重新放
  出来（本轮三轮实测发现）。

配置语法（向后兼容）：`UNC_PREVIEW_REF_LEVELS` 条目
`标签=毫米=类型=锚定`（后两段可选；类型：地面/环氧地坪/华夫板/工字钢/
葡萄架/高架地板/设备/母线；缺省=3.3.6 琥珀线框，旧清单零改动可用；
锚定单跳解析、找不到不猜）+ 可选指令行 `本层=楼层条目标签`。

## 同场修复（3.3.6.2，一并发布）

- **3D 预览永远赶不上点确认**：三个 WebView2 宿主各自开窗各自建环境、
  共用同一数据目录——上一轮退场进程锁目录，新一轮排队 6~10 秒，用户
  在审阅窗点确认（5~10 秒）前 3D 永远起不来。改为**进程级共享环境 +
  启动 Idle 预热**（浏览器进程常驻会话，开窗 0.5 秒级就绪）。
- **模态窗快关炸弹**：窗口 0.4 秒内被关时 WPF-UI TitleBar 的
  ContentRendered 回调拿零句柄调用抛 ArgumentException 炸穿整条命令
  （当日现场一例 U1U failed）。全部 27 处模态调用收口 ModalWindowHost，
  该竞态按取消返回不失败命令。
- 关窗后 WebView2 初始化收尾的误导性「启动失败」WARN 静默。
