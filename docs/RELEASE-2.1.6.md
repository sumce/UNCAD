# UNCAD v2.1.6 XLAYOUT 固定文字位置与 U1U 多选修复

## XLAYOUT 机台 ID

- 取消依赖 DBText 的动态右对齐计算。
- 每行使用统一的固定左侧定位距离 300000。
- 文字使用 BaseLeft，从固定起点向右绘制；不同长度文本不会回落到默认对齐点。
- 文字高度保持 25000。

## U1U 多选图框

- 修复 2.0 之后严格外包框相交判断导致的多重归属错误。
- U1U、U1S、U1DWG 和 XLAYOUT 统一使用图框内实体锚点归属。
- 跨越多个图框的实体按锚点确定唯一图框，不再因外包框相交直接终止批量操作。

版本：2.1.6；程序集和 Bundle 版本：2.1.6.0。
