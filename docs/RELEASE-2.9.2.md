# UNCAD Pro 2.9.2

发布日期：2026-11-01

## 修复：U1F（新建填充）也支持电缆预留

2.9.1 的电缆预留只接在 U1U（更新）路径：U1F 既不按上游类型加盘内预留，也没地方填写/复用设备内预留，写出的 CABLE_INFO 与清单里没有预留。本版补齐 U1F。

- U1F 与 U1U 现在共用同一套预留逻辑：
  - 盘内预留按上游类型：I-Line 盘 3400mm / 插座盘 1200mm / 母线插接口 500mm；
  - 设备内预留从 frameinfo_json 复用；没有记录时在 U1F 的清单确认窗里填写（默认 0，可改），确认后写入 JSON，之后 U1F/U1U 自动预填。
- U1F 的清单确认窗新增「实测电缆 (m)」「设备内预留 (mm)」「盘内预留 (mm)」三行；设备内预留可编辑，实测与盘内只读。
- 命令行汇总新增一行预留明细：实测 + 盘内 + 设备 = 总长（米）。
- CABLE_INFO 仍按 2.9.1 的 mm 格式（分段=实测合计mm（盘内预留）+xxxmm（设备预留）+xxxmm=总长mm）；图上没有实测电缆长度时不做预留。

## 不做 / 说明

- 清单表表格本身的长度列仍是米（M），不随本版改成 mm。
- 批量 U1U 的设备内预留仍是一次 GUI 统一填写（只问本批还没有记录的图框）。
