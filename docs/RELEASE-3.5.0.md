# UNCAD Pro 3.5.0

发布日期：2026-11-22

## 新增（D-055）

### XLAYOUT 清单导入（预勾选）

- 选择窗新增「导入清单…」按钮：从 Excel（.xlsx）或 CSV 导入
  机台ID + 回路名称（设备名称）清单，按清单**预勾选**命中回路、取消其余，
  并显示命中摘要（找不到的条目点名）。清单不是硬过滤——导入后仍可手动
  增删、配合区域/关键词筛选与排列方案（D-045 三模式不变）。
- 表头自动认列：机台 `机台ID/U_机台ID/机台/MachineID/机台编号`；
  回路 `回路名称/U_回路名称/设备名称/回路/设备`。回路列可缺席——
  只有机台ID 的行预勾选整台。认不出机台列时报错并列出可接受列名，
  不猜位置。机台号为空的行跳过；同键条目去重。
- CSV 支持：UTF-8 BOM / 严格 UTF-8 / GBK(936) 自动回退；
  分隔符（逗号/分号/制表符）从表头行自动嗅探。
- 匹配口径与身份一致：D-021（忽略内部空白、大小写不敏感）；
  身份来自图框自身 MACHINEID 属性与 FRAMEINFO（3.4.1.11，D-045 修订），
  与选择集无关。

### XLAYOUT 结果导出（Excel）

- 排版完成后统计窗新增「导出 Excel」按钮，写出
  `<输出根>\UNCAD_XLAYOUT_<时间戳>.xlsx`（与 XSTS 同目录规则，D-035；
  默认根写回、写占用预检、临时文件+替换原子写）。
- 导入清单时：`清单结果` sheet 以清单为纲逐条给出状态——
  `Done`（命中且本次已排版，附图框句柄）/ `未参与排版`（图上有但本次
  未勾选）/ `找不到`（图上没有），备注带机台缺回路/重复等信息；
  `排版图框` sheet 逐框列出本次参与排版的图框。
- 未导入清单时只导出 `排版图框` sheet。
- 导出失败只在窗口内提示，不影响已完成的排版与图纸。

### 附带修正（3.4.1.11，随本版发布）

- XLAYOUT 布局身份只读图框自身属性，设备块 DEVICENAME 不再参与，
  也不再出现「图框属性与设备块不一致」的排版中止；U1S/U1F/U1U 的
  DEVICENAME 硬校验不变。
- XLAYOUT 失败/诊断改为窗口展示（完整列表、可复制），取消路径记入
  操作记录；U1S/U1F/U1U 的 DEVICENAME 候选块来源诊断保留在共享路径。

## 不做什么

- 不改变 XLAYOUT 的既有选择、排列、重复标签行为（D-009 等）。
- 不解析带格式的机台工作簿当清单——清单只认机台ID/回路两列口径；
  机台工作簿仍走 U1SET/U1DATA 快照（D-003/D-012）。
- 导出的 Excel 不回读、不参与统计；它是一次性结果回执。

## 验证

- 定向：`dotnet test UNCAD.slnx --no-restore --filter "FullyQualifiedName~XLayout"`
  通过（80/80，含 Reader/List/Report/Reporter 与两窗口新用例）。
- dotnet test UNCAD.slnx --no-restore：全部通过。
- 真机手工验收：CSV 清单（含图上有的与一两条没有的机台/回路）→
  导入 → 核对预勾选与摘要 → 排版 → 导出 Excel → 核对 Done/找不到 行。

## 新增（D-056 / 3.5.0.1，2026-11-23）

### 回路身份键（同名回路防错）

- 背景：同一机台存在**同名回路但上游编号不同**（如两条 `ECS` 各接不同
  盘柜）。旧版 U1U 按「机台+回路名」取第一条匹配，工作簿实时刷新导致
  行序变化时会**静默**把图框的量更新到另一条同名回路上；U1S/U1DWG 的
  整机回路校验按回路名去重，同名回路塌缩成一条，缺回路会漏判。
- 回路身份键 = 归一化的 `机台ID + 回路名称 + 上游编号`（全半角折叠、
  去空白；回路名保留括号——`AC Rack (630A)` 与 `AC Rack` 是两条回路；
  上游编号去掉尾部槽位号与轴位标注——`2U-UPS5D1-PP-02 40-42(41/Ab)`
  归一为 `2u-ups5d1-pp-02`）。厂务开关、电缆型号等施工中会变的字段
  **不进**身份，仍走字段级变更历史。
- **键不落盘**：frameinfo_json 保持明文原样（机台/回路/上游本来就在档、
  可人工反推），比对时两侧即时计算，口径永远一致。
- U1U 匹配次序：键命中 → 唯一同名 → 同名歧义**弹窗指认**（新「选择同名
  回路」窗：密排候选表含上游编号/厂务开关/电缆/楼层轴位/上游类型/批次，
  底部全字段详情条，双击或确认；指认走正常 U1F/U1U 写入，下次直接命中
  不再询问）。批量 U1U 在预检后统一弹窗，取消的图框记为预检错误。
  U1PDF/三维预览无弹窗路径：报错并跳过。上游改挂（键变但同名唯一）
  照常更新，Fr 变更照记。
- U1S/U1DWG/U1U 整机回路校验改按键口径一一配对：同名双回路只画一条会
  正确判缺，缺项显示上游后缀（如 `ECS（上游 3N-11B1A-PP-02）`）；
  U1DWG 每机台回路数按键去重。老图框（明文身份在档）自动参与键口径。
- 机台数据刷新（U1SET/后台）会点名同机台「同名且同上游编号」的重复行
  （含 Excel 行号），要求修表，不再拖到匹配时才失败。

### U1U 窗口紧凑化（展示更多内容）

- 清单更新对比窗改为「密排图框网格 + 选中详情」：上方一行一图框
  （机台/回路/上游编号/厂务开关/新增/移除/改量/图框，行高 24），点行
  切换下方详情（字段变更、电缆卡、左右清单对比）；单框也显示网格，
  窗口统一尺寸（不再单/多框切 920/1180）。
- 批量确认窗新增「上游编号」「厂务开关」列（行高 32→28），底部新增
  选中行详情条（可收起）。
- 批量结果窗新增「回路」列（按身份键去重计数）。
