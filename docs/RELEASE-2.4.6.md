# Release 2.4.6

## 标注

- `U1Q1/U1Q2/U1Q4` 和 `U1C` 的标注改为**两行 MTEXT**：第一行写固定清单「1.名称」的完整型号（如 梯形桥架200Wx100H），第二行写长度（如 2500mm）。对齐仍为中下，锚点与原单行 `DBText` 同点，位置不变。
- 规格不在固定清单里时**报错中止**，与图框写入一致（D-016）。
- 两行 MTEXT 的行距固定为 **0.75 倍字高**（原默认 1.66 倍，两行显得太散）。

## 统计识别

- 读取端按 **MTEXT 为单位**把两行配对还原成单行写法（`桥架200*100 2500mm` / `⌀20线管 2000mm`），统计引擎继续识别。
- 配对是严格的：第一行必须是固定清单里的桥架/线管型号、第二行必须是纯长度。**孤立的 `2000mm` 与老单行标注照旧按电缆统计**，老图纸一条都不漏。
- 重跑 `U1Q*`/`U1C` 时自动把作用范围内的旧单行标注替换成两行；不重跑就不动。

## 修复

- U1U 更新时，规划行与旧行仅凭名称（如都叫"电缆"）匹配时，不再继承旧行的清单编码与匹配标记——否则会把一个规格的编码盖到另一个规格上，且写出前的两道闸都会放行。
- 桥架旧格数写法（`桥架200*100 12.5格`）迁移成毫米时，若结果不以 0 结尾（如 `12.5×250=3125mm`），统计读不出。现在**不迁移**，保留旧格数写法——统计照样认，避免下一次 U1F/U1U 静默丢掉这条桥架。
- 固定清单 8.11「插座漏电相序检测仪」名字含"插座"却被当成插座行，在清单确认后被策略静默删掉。有固定编码的行现在由编码判定是否插座，不再按名字误删。

## 文档

- README 命令表把 `U1C` 从"按统一设置中的参数绘制软管"改为"按统一设置中的管径绘制线管标注（同时更新图框内 Ruanguan 软管块长度）"。
