# UNCAD Pro 2.10.0

发布日期：2026-11-01

## 新增

- **配置分享（Base64）**：U1SET →「输出与分享」可把本机配置导出为一段 Base64 分享码，
  也可粘贴别人的分享码预览变更后导入；只分享可配置项，授权/账号、时钟水位线、
  更新提示、最近使用记忆等敏感键永不进入分享码。导入走一次原子写入，格式/校验失败给中文原因。
- **操作记录**：每个命令执行都会在本地写一条操作记录（JSONL，默认保留 6 个月），
  包含命令、摘要、结果、耗时、机台数、输出文件与线程号；U1SET →「日志与记录」可直接查看最近记录、
  打开日志/记录目录。文件日志升级为按天文件（`uncad-YYYYMMDD.log`）+ 级别过滤 + 保留天数。
- **整机回路校验**：U1F/U1U/U1S/U1DWG 在生成 BOQ/DWG 之前，要求一个机台在机台数据里的**所有回路**
  都在本次选集中；缺回路时中止并列出缺少的回路，图纸与 BOQ 都不会被修改。
  U1SET 新增开关「整机回路校验」（默认开启），确实不需要绘制全部回路时可关闭。
- **可配置盘内/箱内预留**：U1SET 可分别调整 I-Line 电盘、插座盘、母线插接箱的预留毫米数
  （默认 3400 / 1000 / 500），不必再改程序。
- **输出目录结构**：默认按「图纸名 / 产物类型 / 机台」分层，例如
  `我的文档\UNCAD输出\<图纸>\BOQ\<机台>\[BOQ]<机台>.xlsx`、同级的 `DWG\`、`PDF\`；
  输出根目录为空时自动使用 `我的文档\UNCAD输出` 并写回配置。U1SET 新增两个结构开关。

## 变更

- **UI/UX 商务化**：统一设计令牌与自建组件库（页头、卡片、字段行、状态条、对话框框架、
  表格与工具栏），全部窗体统一间距、标题层级、按钮顺序与错误提示；U1SET 重构为
  概览 / 绘制标注 / 统计汇总 / 文字样式 / 界面与启动 / 机台数据 / 清单与表格 /
  Downstream 自动添加 / 颜色 / 输出与分享 / 日志与记录。
- **性能**：U1F/U1U 不再在 CAD 线程构建并上传等轴测场景，批量 U1U 的分区、统计与写表路径
  进一步减少重复扫描；U1L3D、XLAYOUT、XSTS 在 1000 图框/线段规模做了针对性优化。
- **写占用预检**：BOQ/DWG/PDF 落盘前先探测文件是否被 Excel/AutoCAD 占用，占用时在修改图纸之前
  给出中文提示并中止。
- **PDF 命名**：按机台 + 回路命名，同目录同名不同图时自动追加序号，不再只按回路名导致覆盖。

## 移除

- 移除全部云端上传：回路清单/等轴测上传、DWG/PDF 上传、机台台账上报、成图上传队列与熔断逻辑。
- 移除远程机台数据源：U1SET/U1DATA 只接受本地或 UNC 文件；配置了 HTTP/HTTPS 源时会明确报错，
  不再在启动时后台下载。**账户验证与授权校验保留**（登录、授权状态、单设备绑定不变）。
- 移除已废弃配置键 `UNC_FILL_INCLUDE_UNMATCHED_CONDUITS` 与无用设置项。

## 验证

- `dotnet test UNCAD.slnx`：全部通过。
- `release.ps1 -NoRestore`：构建、Bundle SHA-256、测试、安装包校验、版本一致性全部通过。

## 升级说明

- 升级后首次启动不需要重新登录；原有授权、机台数据和图框记录继续可用。
- 旧的输出目录设置会保留；如需旧的平铺目录结构，在 U1SET 关闭「按图纸名/按类型分目录」。
- 若某个机台在机台数据里存在但图纸尚未绘制全部回路，整机回路校验会阻止生成 BOQ/DWG：
  补画/补选后重试，或临时关闭该开关。
- 旧版平铺目录（`<输出根>\<机台>\...`）里已有的 BOQ/DWG/PDF **不会自动迁移**：新目录首次运行会
  从模板新建 BOQ。需要继续更新旧文件时，在 U1SET 关闭「按图纸名分目录」和「按类型分目录」，
  并把输出根目录指回原来的根目录即可。
