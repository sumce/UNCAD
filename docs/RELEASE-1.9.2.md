# UNCAD v1.9.2 UNC_FILL 别名与待选清单优化

## 修复与改进

- 自动清单匹配改为严格的“类 + 别名”契约。`类`只读取固定清单字段，不再按编码段、项目名称或项目特征推断。
- 类别内的`别名`经过空白、`x/X`与`*`规范化后精确比较；同类别重复别名会报告冲突编码并停止加载，避免随机选择。
- `别名1`继续作为全局唯一迁移别名。新版清单新增`3*35+1*25 -> 1.20 / 3*35+1*16`，既有`32mm -> 3.3 / 38mm`保持不变。
- 从新版`ts.xlsx`重新生成157条内嵌固定清单；运行时仍只需要用户提供机台/设备工作簿。
- 手动补清单窗口改为顶部类别标签，支持“全部、最近使用、电缆、桥架、线管、软管”等实际类别浏览。
- 未匹配电缆、桥架、线管等项目点击“选择未匹配项”或确认填充时，会打开对应类别待选页。
- 替换模式锁定原类别，不能把其他类别的固定清单身份写入当前行。
- 未匹配项目必须选择固定清单身份或明确删除，不能依赖默认未勾选静默跳过。
- 修复固定清单生成脚本的无参数默认路径和 Windows PowerShell UTF-8 中文表头兼容。

## 固定约束

- 固定清单内嵌，用户不提供清单工作簿。
- 空`类`保持空白，不参与自动判定。
- 手动添加只能选择现有固定清单项目并输入数量，不支持自由创建材料身份。
- `别名1`全局唯一，`32mm`仍迁移到`3.3 / 38mm`。
- 线管标注继续使用固定`2000mm`占位。
