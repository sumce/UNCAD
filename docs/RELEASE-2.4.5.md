# Release 2.4.5

## 统计识别

- `U1F`/`U1U`/`UNADD` 支持识别对齐标注/转角标注中人工输入的文字覆盖（如 `2000mm`、`桥架200*100 2500mm`）。
- 只读人工文字覆盖；自动测量（`<>` 或空覆盖）的标注不参与统计，避免几何尺寸线被误计。
- `U1SET` 统计汇总新增"尺寸标注文字 (DIMENSION)"独立开关（`UNADD_DIMENSION_ENABLED`，默认开启）。

## 标注与界面

- 新增 `U1D` 对齐标注转文字：按原位置、原角度生成可编辑单行文字，保留原尺寸线并抑制原标注文字。
- 修复 150% 及以上屏幕缩放下配置中心等窗口输入框与页面显示不全的问题；`TableLayoutPanel` 固定行列样式按 DPI 预缩放。
- U1Q/U1LX 平行线标注重跑通过元数据回溯源线段，不再重复生成；跳过原因逐项提示。
- Xmerge 合并保持块样式签名，批量导入增强。

## 发布校验

- 统一版本：`2.4.5` / `2.4.5.0`。
- 仅生成 `UNCAD Pro` 在线授权包；客户和到期信息继续由 `pro.key` 提供。
