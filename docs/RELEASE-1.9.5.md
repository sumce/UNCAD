# UNCAD v1.9.5 U1 命令规范

## 新版命令

| 命令 | 功能 |
| --- | --- |
| `U1L` | 绘制带长度占位标注的线条 |
| `U1R` | 开拱桥并截断相交直线 |
| `U1Q1` / `U1Q2` / `U1Q4` | 绘制 100 / 200 / 400 mm 桥架标注 |
| `U1F` | 生成单图框清单和属性，自动更新 Excel |
| `U1U` | 单框或多图框批量更新，自动更新 Excel |
| `U1C` | 按统一设置绘制软管 |
| `U1A` | 查看版本、授权和联系方式 |
| `U1S` | 打开统一设置中心 |

## 传统命令

仅保留 `UNL`、`UNR`、`UNQ1`、`UNQ2`、`UNQ4`、`UNADD`。前五个分别复用对应新版绘制实现，`UNADD` 继续提供图纸统计。

## 删除的公开命令

- 不再注册任何 `UNC_*` 命令，包括 v1.9.4 的 `UNC_F` 和 `UNC_UPDATE`。
- 不再注册各模块的 `OPUN*` 设置命令；全部设置统一进入 `U1S`。
- 不再注册 `UNADDX`；统计保留 `UNADD`。
- `UNC_SUBMIT` 继续保持删除状态，`U1F` 和 `U1U` 仍在成功写图后自动更新 `UNCAD_Submissions.xlsx`。

## 部署契约

- AutoCAD bundle 只声明上述 10 个 U1 命令和 6 个传统命令。
- 安装器验证命令集合必须完全一致；任何缺失或额外旧命令都会阻止打包或安装。
- Ribbon 只显示新版任务入口；统计按钮调用保留的 `UNADD`，传统绘制命令不重复显示。
