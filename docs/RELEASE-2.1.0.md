# UNCAD v2.1.0 命令逻辑修复

## 保留范围

- 保留 v1.9.7.16 的全部 18 个已注册命令及其业务功能。
- 保留 U1F、U1U、U1S、U1DWG、U1L、U1R、U1Q1/U1Q2/U1Q4、U1C、U1A、U1SET 及传统兼容命令。
- 不新增或删除业务命令。

## 修复内容

- 选择集解析失败时立即停止，禁止使用不完整对象继续写入图纸。
- 多机台 BOQ 输出增加批次备份和失败恢复，避免留下部分更新结果。
- Ruanguan 长度存在多个冲突值时停止写入并提示用户。
- 图框分区按实体几何范围与图框相交判断，不再只使用实体中心点。
- UNADD 报告遵守电缆、桥架、线管分类开关。
- U1L/UNL 撤销或 ESC 清理失败时明确报告错误，不再静默吞掉异常。
- U1F/U1U 的 BOQ 读取使用当前 CAD 事务，尽量保持 CAD 与 BOQ 的一致性。

## 验证

- Release 构建：0 警告，0 错误。
- 自动化测试覆盖命令注册、统计分类开关、图框相交边界和 BOQ 写入。
- AutoCAD 2022 / .NET Framework 4.8 / x64。
