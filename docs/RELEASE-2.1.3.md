# UNCAD v2.1.3 多图框导出与排版修复

## 问题

2.0 之后 FrameRegionCollector 将全实体导出/排版也改为外包框相交判断。跨越相邻图框的线或辅助对象会同时命中多个边界，导致 U1DWG 和 XLAYOUT 在多选图框时提前失败；单选图框不触发该冲突。

## 修复

- U1U/U1S 保留严格外包框相交判断，用于表格、文字和带业务属性的块的安全预检。
- U1DWG/XLAYOUT 使用全实体锚点归属，兼容 1.9x 的多图框行为。
- 对锚点落在相邻图框公共边界的实体，按距离图框中心和句柄排序确定唯一归属。
- 跨多个图框的实体不再因为几何外包框相交而产生误报。
- 新增回归测试，锁定两种收集策略不能混用。

版本：2.1.3；程序集和 Bundle 版本：2.1.3.0。
