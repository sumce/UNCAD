# UNCAD v1.9.7 DWG 导出视图与元数据

## U1DWG 更新

- 每个机台ID输出一个 DWG：

  `用户选择的文件夹\机台ID\机台ID.dwg`
- 同一机台的设备图框横向排列，相邻图框间距固定为 10000。
- 导出使用完整 Wblock 依赖，保留源图的线条、图层、线型、文字样式、标注样式、块定义和块属性。
- 输出 DWG 的保存视图以第一个图框的中心为中心，方便打开文件后快速定位第一个设备框。
- 第一个图框左侧添加机台ID标题，标题文字高度固定为 25000。
- 标题下方依次添加：

  - `UNSIAO Work™`
  - 生成时间
  - 软件版本
  - Windows User

- 源图纸不修改、不保存；同名机台 DWG 重新导出时覆盖目标文件。
