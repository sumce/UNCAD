# UNCAD Pro 2.9.3

发布日期：2026-11-01

## 变更：CABLE_INFO 写法与电缆预留规则按现场口径统一

图框 CABLE_INFO 改成现场使用的样式：全部 mm，明细统一写成「数值（说明）」，最后 =总长mm。

示例：

    电缆ZB-YJVR-5*4mm²: 1000+700+4800+6500+3400（盘内）+2000（设备内）+3000（预留）=18400mm

- 分段之间直接用 + 连接，不再出现中间的 `=实测合计`；
- 盘内/箱内、设备内、业主预留都写成 `数值（说明）`；
- 括号里分别是：盘内、箱内、设备内、预留；
- 总长仍按「实测 + 盘内/箱内 + 设备内 + 业主预留」计算。

## 预留规则（按现场口径）

| 上游类型 | 预留 | 说明 |
| --- | --- | --- |
| I-Line 盘 | 3400 | 盘内 |
| 插座盘 | 1000 | 盘内（原 1200） |
| 母线插接箱 / 插接口 | 500 | 箱内（原 500 盘内） |
| 业主统一预留 | 3000 | 预留，所有回路默认加 |
| 设备内预留 | 用户填写 | 设备内，逐框可改，写入 frameinfo_json |

- U1SET →「清单与表格」新增「电缆业主预留（mm）」，默认 3000；填 0 表示不加。
- U1F 与 U1U 完全一致；清单表数量仍按米，BOQ 数量仍按米（总长含预留）。

## 兼容性

- 旧图纸/旧 BOQ 里的 CABLE_INFO 是旧写法（`分段=实测mm（盘内预留）+…`）：读取时仍按最后一个 `=xxxmm` 取总长，重跑 U1F/U1U 后会改写成新写法。
- 图框 CABLE_INFO 增加「电缆」前缀；BOQ/清单型号反向解析会剥掉该前缀，不影响清单匹配。
