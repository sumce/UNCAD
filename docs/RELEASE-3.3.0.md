# UNCAD Pro 3.3.0

发布日期：2026-11-17

## 新增

- **法定图层规范 + 自动矫正（D-054 特性①）**：`U_CABLE`（电缆路由，色号 7）、
  `U_TRAY`（桥架，色号 1）、`U_CONDUIT`（线管，色号 4）三个法定图层缺失自动
  创建；U1U/U1F 把识别出的插件实体移正到对应图层（识别依据：扫描器认出的
  U1L 线段与毫米标、带平行标注元数据的 U1Q/U1C 输出），矫正进既有写事务
  （一次 U 可回退），确认窗/批量预检列出移正计数；无法判定的输出点名报告、
  绝不猜测。U1L/U1LX 新生成的线+毫米标直接落在 U_CABLE。开关
  `UNC_FILL_LAYER_GOVERNOR`（默认开）。实体颜色不变，只改图层归属。
- **连通性检查 + Polyline 扫描（D-054 特性②）**：U1LX 扫描器接受开放
  LWPOLYLINE（U1R/Xauto 开洞线）为一个段（起点=首顶点、终点=末顶点）；新增
  纯分析器输出连通分量/孤立段清单；批量 U1U 确认窗新增「连通性」列，单框
  U1F/U1U 命令行输出诊断。**报告级不拦截**。Xauto 对含开洞 Polyline 的分量
  整分量跳过重排并点名（比旧版更安全）。
- **U1U 3D 预览（D-054 特性③）**：单框 U1U 确认窗与批量 U1U 确认窗左侧新增
  WPF Canvas 自绘的 3D 路由预览（正交轨道相机：拖动旋转/滚轮缩放/双击复位；
  无第三方 3D 库）。场景按毫米标重建并整体地面归零；柱位摘要按台账轴位解析
  （容错「48/V」「48-V」「48」「V」，解析失败显示原文），如「上游 48/V ↔
  下游 37/V · Δ11 跨 × 4.8m ≈ 52.8m」。批量窗选中行切换该框场景。
- **U1Q/U1C 归属识别（D-054 特性④）**：SOURCE/RUN → 宿主电缆段映射 API，
  图层矫正消费；预览不画桥架/线管叠加（留后续）。
