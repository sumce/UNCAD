# UNCAD Pro 2.6.6

发布日期：2026-10-11（内部版本 2.6.6.0）

## 本次新增：U1U / U1F 自动上传等轴测（3D）数据

- 执行 **U1U / U1F** 时，该图框（= 该回路）的**等轴测场景**会与清单**同一次提交**自动上传到云端。
- 官网项目页的 **「ISO 图」** 栏可以直接在线查看：渲染器与客户端 **U1L3D 完全相同**
  （同一份场景数据：节点/路由/桥架、4800mm 轴距、上游/下游轴位、方向标记），
  不再需要截图或导出文件。
- 不需要任何新命令、不需要额外操作：**U1U/U1F 照旧执行即可**。

## 行为说明

- 3D 数据与本地 U1L3D 预览是**同一份**场景：网页看到的和你在 CAD 里看到的一致。
- 图框内**没有带毫米标注的 U1L 线段**时不会有 3D 数据，只上传清单 —— 这是正常情况，
  命令行不会报错。
- 场景构建失败或超过上限（100 万字符）时**只记日志**，不影响清单上传，也不影响图纸与 BOQ；
  U1U/U1F 的结果与之前的版本完全一致。
- 构建耗时写入日志，便于后续按需优化（批量 U1U 每个图框各构建一次）。

## 升级方式

在客户端「客户端下载」页或官网发布页下载 2.6.6 安装包，覆盖安装即可；
登录状态与本地设置保留。
