# UNCAD v1.9.1 回归修复

## 修复内容

- `UNC_FILL` 在确认入口强制提交当前复选框编辑，并从所有可见行重新同步最终选择；取消插座后立即确认也不会进入 `SelectedRows()` 或 CAD 表格写入。
- 最终确认的清单编码和名称写入运行日志，后续可直接核对界面选择与实际输出。
- `UNC_CONDUIT` 删除实测长度格式化入口，所有管径固定生成 `2000mm` 人工占位文字。
- 修正 AutoCAD 配置存储的宿主类型和注册表路径，移除读取配置时反射调用 `Application.GetSystemVariable("CPROFILE")` 的递归风险，解决 `UNC_CONDUIT` 进入命令时可能发生的宿主栈溢出。
- 平行曲线生成在实体入库前预检长度、中点、切线和文字位置；损坏、退化或无法偏移的单条曲线会被跳过并记录对象 ID，不再中断其他有效曲线。

## 固定业务契约

- 固定清单继续内嵌，手动添加只能选择已有数据库条目。
- 空白 `类` 保持空白，不进行推断。
- 主别名按类别匹配；全局唯一 `别名1` 负责迁移，`32mm` 仍解析到 `3.3 / 38mm`。
- 线管标注中的 `2000mm` 是占位符，不代表图上几何距离。

## 回归门槛

- 覆盖取消插座后不切换单元格、直接确认的 WinForms 测试。
- 覆盖线管格式化器不再暴露实测长度重载的契约测试。
- 正式版和临时授权版均需通过 Release 全量测试、包校验和 AutoCAD 2022 宿主加载。
