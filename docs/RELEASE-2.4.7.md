# Release 2.4.7

## BOQ 自动填充

- `U1SET` 新增独立“电盘”开关；电盘、断路器和插座盘分别控制。
- `I-Line盘` 按固定清单分别生成电盘与断路器，不再用同一个类别或开关代替。
- 电盘继续按固定清单类别与额定电流精确匹配，不自动猜测相邻规格。

## U1U 更新

- 长两行线管 MTEXT 改用文字插入点或对齐点归属图框，避免外包框中心落入相邻图框后漏统计。
- 有新线管测量结果时更新现有数量；无法确认测量范围时继续保留原数量。
- `Ruanguan` 动态块仍是软管自动长度的唯一来源。

## 桥架标注

- `U1F/U1U` 自动把旧桥架标注升级为固定清单 BOQ 型号加长度的两行样式。
- 迁移时保留旧标注角度，并修复已经迁移但错误变为水平的标注。

## 界面与时间

- 优化 `U1SET`、在线授权与关于窗口的 WinForms 页面、卡片和操作布局。
- 构建时间统一显示为 UTC+8。

## 发布校验

- 统一版本：`2.4.7` / `2.4.7.0`。
- 仅生成 `UNCAD Pro` 在线授权包；客户和到期信息继续由 `pro.key` 提供。
