# UNCAD Pro 3.4.0

发布日期：2026-11-18

## 变更（重构：3D 预览内核换 WPF 原生 Viewport3D）

影响命令：`U1U`（清单确认窗 3D 路由预览）、`U13D`（多图框三维预览）。

- 用户指令「算了 用 Viewport3D吧」——WebView2+three.js 内核（3.3.5~3.3.8）
  在本机被 WebView2 用户数据目录锁同步阻塞 STA 线程，「正在启动三维渲染
  器」白屏反复复发（2026-11-18 日志：10:32:35 控制器创建 30s 超时降级、
  15:02 预热窗 123ms 已建仍复白）。浏览器内核的外部进程/目录锁/airspace
  白窗/随窗退场四样病根无法根治，整条路退役。
- U1U/U13D 渲染内核换 **WPF 原生 Viewport3D**（.NET Framework 自带，零第
  三方包）：SetModel/构造 **同步** 出场景，不存在任何「启动中」中间态；
  参照建筑模型（楼板/环氧/华夫圆孔板/工字钢/葡萄架/设备/母线玻璃/结构柱/
  1F 地面）视觉公式与 3.3.7~3.3.8 页面逐条对齐，本层重定位与包络推算保留；
  U13D 正交相机/轴位网格/罗盘/回路·桥架·图框·诊断面板全保留。
- 退役并删除：QuickLineWebPreviewControl、OrbitPrewarmHost（预热+孤儿清
  扫）、Web 页面树（three.js vendor 10 文件）；payload allow-list 26→16 项；
  csproj 去 System.Management；Bootstrap 预热挂钩摘除。
- **登录页 WebView2 不动**（账户/许可校验，D-025 唯一网络功能）。
- 明确不做：不引入 HelixToolkit 或任何第三方 3D 库（3.3.5 条款仍守）；
  3D 预览仍然只读，不写 CAD 实体、不刷新工作簿、不访问网络。

## 3.4.0.4 补丁

- U1U/U13D 默认继续使用 WPF Viewport3D，并新增 WebV / Three.js 独立窗口入口；WebView2 仅在独立辅助进程初始化，不会卡住 AutoCAD。两个模式直接使用同一份已构建网格、相机参数和标签锚点。
- WebV 使用每窗口独立临时目录和虚拟主机；不允许远程导航/资源、下载、权限或宿主对象。启动超时或渲染异常不影响 WPF 预览与清单流程。
- 修复毫米标与路线长度不一致：U1U/U13D 都按毫米标注值建模，包括未确认的 `2500mm` 等 `00mm` 标签；该占位画长规则只保留给 Xauto。
- 添加 2500/2000/44000mm 段长回归、WPF 网格与 WebV 导出网格逐点一致性测试。
- 验证：定向 45 项通过；Debug/Release 全量各 1608 项通过；发布流程 AutoCAD PERF_SMOKE、MIGRATION_SELFTEST、26 文件包校验通过。Playwright 检查 WebV 合成场景在 1280×800 和 420×600 均非空、旋转后像素变化、标签可见。
- 未验证真实 AutoCAD 内的 WebView2 Runtime/GPU 行为；WPF 为可直接使用的默认与回退路径。
- 安装包：`artifacts/Pro/UNCAD-Pro-v3.4.0.4.zip`，SHA-256 `8818F0827C8C20AD14CAAEC21902E959D9E04B2CC22559C4734766BD3D2AF5D2`。
- 本次未覆盖当前用户安装目录：安装器检测到 AutoCAD 正在运行并安全中止。关闭 AutoCAD 后运行 `.\installer.ps1 -Mode InstallUser`，再运行 `.\installer.ps1 -Mode VerifyUser`。

## 3.4.0.7 补丁

- U1U 上下游轴位现在对应多段路线的两个拓扑端点，不再按画面 X 坐标的左右极值判断；数字/字母轴位方向依据用户确认的等测草图北向约定与工作簿轴位跨度校验。
- 路线分叉、端点数量不为二、轴位无效或轴位方向与路线不符时，不猜上下游；预览保留路线和柱网，隐藏端点轴位标记与上游柜体，并显示诊断。不会阻止清单写入。
- 新增转弯路线“上游位于较大 X 端”、无效轴位、分叉不猜和方向未确认时保留柱网的回归测试。
