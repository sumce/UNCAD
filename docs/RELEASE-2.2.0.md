# UNCAD v2.2.0 U1F/U1U 清单同步

版本：2.2.0；程序集和 Bundle 版本：2.2.0.0。

## U1F

- 首次生成按固定内嵌清单匹配电缆型号，并由电缆型号推导软管直径。
- 图框内存在 `Ruanguan` 块时读取其毫米或米长度，写入软管清单；没有有效长度不生成软管行。
- `NEXT=插座盘` 会生成对应 4.11/4.12 插座盘项目；Device 动态块状态决定是否追加 8.2/8.3 插座项目。

## U1U

- 选中单个 `frame_20260812` 会自动收集同框对象。批量图框先完成全部预检，再一次性写入 CAD 和 BOQ。
- 电缆型号按图框属性、当前清单和固定清单依次匹配；多个图框存在未匹配型号时在一个窗口中批量选择，取消即不修改图纸。
- 新统计文字覆盖电缆、桥架、线管数量；没有新统计文字时保留现有数量。`Ruanguan` 长度始终覆盖软管行，删除块则删除软管行。
- 插座数量不能从 CAD 推断：已有 8.x 行的数量、型号和描述完整保留；仅在插座状态且没有 8.x 行时新增数量 1，设备状态恢复后删除 8.x 行。

## U1C / U1Q / U1L

- `U1C` 在预选 Ruanguan 块或图框时，会按当前软管直径把可识别的长度属性规范为 `20mm软管:1500mm`；坐标等动态几何属性不会被当成长度。
- `U1Q1/U1Q2/U1Q4` 和自定义 U1Q 文字统一输出“桥架型号 + 总长度 mm”。旧的“桥架型号 + 格数格”会按 `UNADD_MM_PER_GRID` 换算为毫米。
- 图框内可放置独立 `frameinfo_json` 块；U1F/U1U 会记录机台、设备、原始/BOQ 电缆型号、软管直径、最后修改时间和变更历史。旧版 `frame_20260812` 如果没有独立块，或只有空的 `FRAMEINFO_JSON` 属性，会在 U1F/U1U 执行时自动迁移，保留旧图框几何和现有属性；已有独立块不会重复插入。U1U 优先使用其中保存的 BOQ 替代型号。
- 批量 U1U 遇到已合并或未匹配固定清单的行时会集中询问是否采用默认数据；确认后占位行可写入 CAD 表格，但没有项目编码的行不会猜测提交到自动 BOQ。
- `U1L` 只接受正数毫米占位文字；非法设置自动回退为 `2000mm`，不会把软管或桥架文字混入线段标注。

## 发布与安装

关闭 AutoCAD 后运行 `installer.ps1 -Mode InstallUser` 安装 2.2.0（全局安装使用 `InstallAll`）。安装完成后重新启动 AutoCAD，使用 `U1HELP` 检查命令列表。
