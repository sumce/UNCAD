# UNCAD v1.9.7.11 品牌、授权与界面优化

## 变更

- 统一产品品牌为 UNCAD，公司名称为 UNSIAO.Ltd，官网为 https://www.unsiao.com。
- 关于窗口拆分为产品信息、授权状态、使用条款和关于 UNSIAO 四个页签。
- 授权模式和有效期使用集中元数据；当前构建为正式版、无期限。有效期版本应同步修改授权模式、到期日、PackageContents.xml 和发布包。
- 授权过期后，U1F、U1U 和 U1DWG 在执行入口拒绝运行。
- Ribbon 改为清单、标注、统计、系统四个面板，首要动作固定为 U1F、U1U 和 U1DWG。
- U1S 和 U1F 窗口统一背景、按钮、表格行、页签和来源提示。

## 法律说明

界面中的使用条款是产品提示文本，不构成法律意见。正式对外发布前，应由 UNSIAO.Ltd 法务或律师审核最终版本。
