# UNCAD Pro 3.3.1

发布日期：2026-11-17

## 新增

U1U 3D 路由预览增强（D-054 Amendment，用户现场四条反馈，只影响 U1U 确认窗
的预览展示，不动任何写入语义）：

- 窗口对半分（反馈"不要跟清单确认挤到一块 相当于一个窗口分成两半"）：单框
  清单确认窗与批量确认窗的预览改为左半——两个 Star 列 + 中间 GridSplitter
  可拖动（两侧各 250px 最小宽度保护）；预览为空（U1F/旧行为）时列宽回 0、
  分隔条隐藏。3.3.0 的固定 300/320px 窄条废弃。
- 米数标记（反馈"每条线也没有米数标记"）：每段中点标毫米标原文，固定屏幕
  字号、浅底可读；段投影长度低于 24px 时该段标签自动隐藏。
- 柱位进场景（反馈"3D预览内展示柱位 你没展示"）：地面按 4800mm 柱距画柱网
  （可开关，默认开），路由两端端点钉上游/下游轴位原文标签，两端数字轴可
  解析时按路由 X 跨度线性插值标数（48、47、46…）；解析失败只画网格不猜。
- 桥架/线管双线通道（反馈"3D预览没有展示桥架"）：归属到本框宿主段的 U1Q
  输出画红色双线+浅红半透明填充（偏移=桥架宽/2，宽度取 U1Q 标注文本，解析
  不出按 200 缺省并在图例注明）；U1C 输出画青色双线细间距；角落图例注明
  橙X/绿Y/蓝Z/红=桥架(宽)/青=线管。

修复（顺手）：3.3.0 预览的滚轮缩放实际是视觉空操作（自动适配把 Zoom 整除），
现缩放真实生效；复位画面与 3.3.0 一致。

不做：不往图纸里写任何柱网/通道几何；不改 U1F/U1U 写入与统计语义；归属只认
元数据宿主解析，不按颜色/文本猜测。
